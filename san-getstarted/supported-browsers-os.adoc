= SANtricity ソフトウェアブラウザとオペレーティングシステムのサポート
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricityソフトウェアは、複数のブラウザとオペレーティング システムをサポートしています。



== ブラウザ

サポートされるブラウザとバージョンを次に示します。

[cols="1a,1a"]
|===
| ブラウザ | 最小バージョン 


 a| 
Google Chrome
 a| 
89



 a| 
Mozilla Firefox
 a| 
80



 a| 
Safari
 a| 
14



 a| 
Microsoft Edge
 a| 
90

|===
[NOTE]
====
Unified Managerを使用するためには、Web Services Proxyがインストールされていて、ブラウザから使用できる必要があります。詳細については、 https://docs.netapp.com/us-en/e-series/web-services-proxy/index.html["SANtricity Web Services Proxyの概要"^]を参照してください。

====
