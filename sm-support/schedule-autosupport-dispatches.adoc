= SANtricity System ManagerでAutoSupportの送信をスケジュールする
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity System Managerは、AutoSupportディスパッチのデフォルトスケジュールを自動的に作成します。必要に応じて、独自のスケジュールを指定できます。

.開始する前に
AutoSupport機能が有効になっている必要があります。有効になっているかどうかは[AutoSupport]ページで確認できます。

.タスク概要
* *毎日の時刻* -- 指定した時間範囲内に、毎日ディスパッチが収集され送信されます。System Managerは、その範囲内でランダムな時刻を選択します。すべての時刻は協定世界時（UTC）で表示されます。これは、ストレージアレイのローカル時刻とは異なる場合があります。ストレージアレイのローカル時刻をUTCに変換する必要があります。
* *週ごとの配信* -- 週ごとの配信は週に一度まとめて送信されます。System Managerは、指定した曜日の中からランダムに1日を選択します。週ごとの配信を許可しない曜日は、選択を解除してください。System Managerは、許可した曜日の中からランダムに1日を選択します。
* *週単位* -- 週ごとの配信は、お客様が指定した期間内に週に一度収集され、送信されます。System Managerは、指定された範囲内でランダムな時刻を選択します。時刻はすべて協定世界時（UTC）であり、ストレージアレイの現地時間とは異なる場合があります。ストレージアレイのローカル時刻をUTCに変換する必要があります。


.手順
. メニューを選択：サポート[サポートセンター > AutoSupport]タブ。
. *スケジュール AutoSupport ディスパッチ*を選択します。
+
スケジュールAutoSupportディスパッチウィザードが表示されます。

. ウィザードの手順に従います。
