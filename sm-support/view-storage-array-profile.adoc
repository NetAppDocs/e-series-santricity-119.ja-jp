= SANtricity System Managerでストレージアレイのプロファイルを表示する
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ストレージ アレイ プロファイルには、ストレージ アレイのすべてのコンポーネントとプロパティの説明が表示されます。

.タスク概要
ストレージ アレイ プロファイルは、リカバリ時の補助として、またはストレージ アレイの現在の構成の概要として使用できます。管理クライアントにストレージ アレイ プロファイルのコピーを保存したり、ストレージ アレイ プロファイルのハード コピーをストレージ アレイとともに保管したりすることもできます。構成を変更する場合は、ストレージ アレイ プロファイルの新しいコピーを作成してください。

.手順
. メニューの「サポート」→「サポートセンター」→「サポートリソース」タブを選択します。
. *Launch detailed storage array information* までスクロールダウンし、 *Storage Array Profile* を選択します。
+
画面にレポートが表示されます。

+
.フィールドの詳細
[%collapsible]
====
[cols="25h,~"]
|===
| セクション | 概要 


 a| 
ストレージ アレイ
 a| 
ストレージ アレイについて設定可能なすべてのオプションとシステムの静的オプションが表示されます。これらのオプションには、コントローラ / ドライブ シェルフ / ドライブ / ディスク プール / ボリューム グループ / ボリューム / ホットスペア ドライブの数、ドライブ シェルフ / ドライブ / ソリッド ステート ディスク（SSD） / ボリュームの許可される最大数、Snapshotグループ / Snapshotイメージ / Snapshotボリューム / 整合性グループの数、機能に関する情報、ファームウェア バージョンに関する情報、シャーシのシリアル番号に関する情報、AutoSupportのステータスとAutoSupportのスケジュールの情報、サポート データの自動収集とスケジュールされたサポート データ収集の設定、ストレージ アレイのWorld Wide Identifier（WWID）、およびメディア スキャンとキャッシュの設定が含まれます。



 a| 
ストレージ
 a| 
ストレージ アレイ内のすべてのストレージ デバイスのリストが表示されます。ストレージ アレイの構成に応じて、[ストレージ]セクションには以下のサブセクションが表示される場合があります。

** *Disk Pools* -- ストレージアレイ内のすべてのDisk Poolsの一覧を表示します。
** *ボリュームグループ* -- ストレージアレイ内のすべてのボリュームグループの一覧を表示します。ボリュームと空き容量は、作成された順に記載されています。
** *ボリューム* -- ストレージアレイ内のすべてのボリュームのリストを表示します。表示される情報には、ボリューム名、ボリュームの状態、容量、RAIDレベル、ボリュームグループまたはディスクプール、ドライブの種類、およびその他の詳細情報が含まれます。
** *欠落ボリューム* -- 現在欠落状態となっているストレージアレイ内のすべてのボリュームのリストを表示します。記載されている情報には、各欠落ボリュームのWorld Wide Identifier（WWID）が含まれています。




 a| 
コピー サービス
 a| 
ストレージ アレイに使用されるすべてのコピー サービスのリストが表示されます。ストレージ アレイの構成に応じて、[コピー サービス]セクションには以下のサブセクションが表示される場合があります。

** *ボリュームコピー* -- ストレージアレイ内のすべてのコピーペアのリストを表示します。表示される情報には、コピー数、コピーペア名、ステータス、開始タイムスタンプ、およびその他の詳細情報が含まれます。
** *Snapshot Groups* -- ストレージアレイ内のすべてのスナップショットグループの一覧を表示します。
** * Snapshot イメージ * -- ストレージアレイ内のすべての Snapshot のリストを表示します。
** * Snapshot Volumes * -- ストレージアレイ内のすべてのスナップショットボリュームのリストを表示します。
** *整合性グループ* -- ストレージアレイ内のすべての整合性グループの一覧を表示します。
** *メンバーボリューム* -- ストレージアレイ内のすべての整合性グループメンバーボリュームのリストを表示します。
** *ミラーグループ* -- ミラーリングされたすべてのボリュームのリストを表示します。
** *Reserved Capacity* -- ストレージアレイ内のすべてのReserved Capacityボリュームのリストを表示します。




 a| 
ホストの割り当て
 a| 
ストレージ アレイにおけるホスト割り当てのリストが表示されます。表示される情報には、ボリューム名、論理ユニット番号（LUN）、コントローラID、ホスト名またはホスト クラスタ名、およびボリューム ステータスがあります。そのほか、トポロジの定義やホスト タイプの定義も表示されます。



 a| 
ハードウェア
 a| 
ストレージ アレイ内のすべてのハードウェアのリストが表示されます。ストレージ アレイの構成に応じて、[ハードウェア]セクションには以下のサブセクションが表示される場合があります。

** *コントローラ* -- ストレージアレイ内のすべてのコントローラのリストが表示され、コントローラの場所、ステータス、および構成が含まれます。また、ドライブチャネル情報、ホストチャネル情報、およびイーサネットポート情報も含まれます。
** *ドライブ* -- ストレージアレイ内のすべてのドライブのリストを表示します。ドライブは、シェルフID、ドロワーID、スロットIDの順にリストされています。表示される情報には、各ドライブのシェルフID、ドロワーID、スロットID、ステータス、raw容量、メディアタイプ、インターフェイスタイプ、現在のデータレート、製品ID、およびファームウェアバージョンが含まれます。ドライブセクションには、ドライブチャネル情報、ホットスペアのカバー範囲情報、および摩耗寿命情報（SSDドライブのみ）も含まれています。摩耗寿命に関する情報には、使用済み耐久性の割合が含まれます。これは、SSDドライブにこれまでに書き込まれたデータ量を、ドライブの理論上の総書き込み制限量で割った値です。
** *ドライブチャネル* -- ストレージアレイ内のすべてのドライブチャネルの情報を表示します。表示される情報には、チャネルの状態、リンクの状態（該当する場合）、ドライブ数、および累積エラー数が含まれます。
** *シェルフ* -- ストレージアレイ内のすべてのシェルフの情報を表示します。記載されている情報には、ドライブの種類、およびシェルフの各コンポーネントのステータス情報が含まれます。シェルフコンポーネントには、バッテリパック、Small Form-factor Pluggable（SFP）トランシーバ、電源ファンキャニスタ、または入出力モジュール（IOM）キャニスタなどが含まれる場合があります。ストレージアレイでセキュリティキーが使用されている場合、ハードウェアセクションにはセキュリティキー識別子も表示されます。




 a| 
機能
 a| 
インストールされている機能パックのリスト、および1つのホストまたはホスト クラスタで許容されるSnapshotグループ、Snapshot（従来のもの）、ボリュームの最大数が表示されます。[機能]セクションの情報には、ドライブ セキュリティ（ストレージ アレイのセキュリティが有効か無効か）も含まれます。

|===
====
. ストレージアレイプロファイルを検索するには、*Find*テキストボックスに検索語を入力し、*Find*をクリックします。
+
一致するすべての用語が強調表示されます。すべての結果を1つずつスクロールするには、*検索*をクリックし続けます。

. ストレージアレイプロファイルを保存するには、*保存*をクリックします。
+
ファイルは、ブラウザのダウンロードフォルダに次の名前で保存されます `storage-array-profile.txt`。
