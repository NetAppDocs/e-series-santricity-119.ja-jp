= SANtricity System Managerでサポートを受ける
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
サポート ページからテクニカル サポートのリソースにアクセスできます。



[[what-support-tasks-are-available]]
== どのようなサポート タスクを実行できますか?

テクニカル サポートの連絡先の表示、診断の実行、AutoSupportの設定、イベント ログの表示、ソフトウェア アップグレードの実行が可能です。

詳細については、以下を参照してください。

* link:autosupport-feature-overview.html["AutoSupport機能の概要"]
* link:overview-event-log.html["イベント ログの概要"]
* link:overview-upgrade-center.html["アップグレード センターの概要"]




[[how-do-i-contact-technical-support]]
== テクニカル サポートに連絡するにはどうすればよいですか?

メイン ページから、menu:Support[Support Center > Support Resources tab]をクリックします。技術サポートの連絡先情報は、インターフェイスの右上に記載されています。
