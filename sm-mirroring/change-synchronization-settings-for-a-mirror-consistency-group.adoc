= SANtricity System Managerでミラー整合性グループの同期設定を変更する
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ローカル ストレージ アレイのミラー整合性グループがデータの初回同期時や非同期ミラーリング処理中のデータの再同期時に使用する、同期設定と警告しきい値を変更できます。

.タスク概要
同期設定を変更すると、ミラー整合性グループ内のすべてのミラー ペアの同期処理に適用されます。

.手順
. メニュー：Storage[Asynchronous Mirroring]を選択します。
. *Mirror Consistency Groups*タブを選択します。
+
[ミラー整合性グループ]テーブルが表示されます。このテーブルには、ストレージ アレイに関連付けられているミラー整合性グループがすべて表示されます。

. 編集するミラー整合性グループを選択し、メニューから More （その他） [Edit Settings] （設定の編集）を選択します。
+
[設定の編集]ダイアログ ボックスが表示されます。

. 必要に応じて同期設定とアラート設定を編集し、*保存*をクリックします。
+
.フィールドの詳細
[%collapsible]
====
[cols="25h,~"]
|===
| フィールド | 概要 


 a| 
ミラー ペアを同期する方法を選択...
 a| 
リモートストレージアレイ上のミラーリングされたペアを、手動で同期するか自動で同期するかを指定します。

** **手動** – このオプションを選択すると、リモート ストレージ アレイ上のミラーリングされたペアを手動で同期できます。
** **自動的に、毎回** – このオプションを選択すると、前回の更新の開始から次回の更新の開始までの時間間隔を指定して、リモートストレージアレイ上のミラーペアを自動的に同期します。デフォルトの間隔は 10 分です。




 a| 
アラートを受け取る条件を選択...
 a| 
同期方法を自動に設定した場合に、次のアラートを設定します。

** **同期** – System Managerが同期が完了していないことを警告するまでの時間を設定します。
** **リモート リカバリ ポイント** – System Manager が、リモート ストレージ アレイ上のリカバリ ポイント データが定義した時間制限よりも古いことを示すアラートを送信するまでの時間制限を設定します。前回の更新終了時点からの時間制限を定義します。
** **リザーブ容量のしきい値** – System Manager がリザーブ容量のしきい値に近づいていることを通知するアラートを送信するリザーブ容量の量を定義します。残り容量のパーセンテージでしきい値を定義します。


|===
====


.結果
System Managerによって、ミラー整合性グループ内のすべてのミラー ペアの同期設定が変更されます。
