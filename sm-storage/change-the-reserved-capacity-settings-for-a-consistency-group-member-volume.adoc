= SANtricity System Managerで整合性グループ メンバー ボリュームの予約容量設定を変更します
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
整合性グループのメンバーボリュームの設定を変更して、メンバーボリュームの予約容量がフルに近づいたときにSANtricity System Managerがアラート通知を送信するパーセンテージポイントを調整したり、予約容量が定義された最大パーセンテージに達したときに使用するポリシーを変更したりできます。

.タスク概要
個々のメンバー ボリュームのリザーブ容量設定を変更すると、整合性グループに関連付けられているすべてのメンバー ボリュームのリザーブ容量設定も変更されます。

.手順
. メニュー：Storage[Pools & Volume Groups]を選択します。
. * Reserved Capacity * タブをクリックします。
. 編集したい整合性グループのメンバーボリュームを選択し、*設定の表示/編集*をクリックします。
+
メンバーボリューム予約容量設定ダイアログボックスが表示されます。

. メンバー ボリュームのリザーブ容量設定を適宜変更します。
+
.フィールドの詳細
[%collapsible]
====
[cols="25h,~"]
|===
| 設定 | 概要 


 a| 
アラートの送信しきい値...
 a| 
スピナーボックスを使用して、メンバーボリュームの予約容量が満杯に近づいたときにSystem Managerがアラート通知を送信するパーセンテージポイントを調整します。

メンバーボリュームの予約容量が指定されたしきい値を超えると、System Managerはアラートを送信し、予約容量を増やすか、不要なオブジェクトを削除する時間を与えます。


NOTE: 1つのメンバーボリュームのアラート設定を変更すると、同じ整合性グループに属する_すべて_のメンバーボリュームのアラート設定が変更されます。



 a| 
リザーブ容量がフルになったときの処理
 a| 
次のいずれかのポリシーを選択できます。

** *最も古いSnapshotイメージの削除* -- System Managerは、整合性グループ内で最も古いSnapshotイメージを自動的に削除し、グループ内で再利用するためにメンバーの予約済み容量を解放します。
** *ベースボリュームへの書き込みを拒否* -- 予約容量が定義された最大パーセンテージに達すると、System Managerは、予約容量へのアクセスをトリガーしたベースボリュームへのI/O書き込み要求を拒否します。


|===
====
. 変更を適用するには、*保存*をクリックしてください。


.結果
System Managerは、メンバーボリュームの予約容量設定を変更するだけでなく、整合性グループ内のすべてのメンバーボリュームの予約容量設定も変更します。
