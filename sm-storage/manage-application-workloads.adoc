= SANtricity System Managerでアプリケーションとワークロードを管理
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
アプリケーションとワークロードを管理して、ストレージ アレイ上の既存のすべてのボリュームをワークロード名とアプリケーション タイプでグループ化して表示できます。既存または新規のワークロードにボリュームを追加したり、既存のワークロードの設定を変更したり、新しいボリュームとワークロードを作成することもできます。
