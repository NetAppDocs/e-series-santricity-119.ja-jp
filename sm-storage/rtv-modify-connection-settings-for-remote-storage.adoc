= SANtricity System Managerでリモートストレージの接続設定を変更します
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
[設定の表示 / 編集]オプションを使用して、リモート ストレージ構成の接続設定を編集、追加、または削除できます。

.タスク概要
接続プロパティを変更すると、実行中のインポートに影響します。処理の中断を回避するため、接続プロパティの変更はインポートを実行していないときに行ってください。

.手順
. メニュー：Storage[Remote storage]を選択します。
. リストから、変更するリモート ストレージ オブジェクトを選択します。
. *View/Edit Settings*をクリックします。
+
[リモート ストレージ設定]ダイアログ ボックスが表示されます。

. *Connection Properties*タブをクリックします。
+
リモート ストレージ インポートに対して設定されているIPアドレスとポートが表示されます。

. 次のいずれかを実行します。
+
** *Edit* -- リモートストレージオブジェクトに対応する行項目の横にある *Edit* をクリックします。修正後のIPアドレスおよび/またはポート情報を該当欄に入力してください。
** *追加* -- *追加*をクリックし、指定されたフィールドに新しいIPアドレスとポート情報を入力します。*追加*をクリックして確定すると、新しい接続がリモートストレージオブジェクトのリストに表示されます。
** *削除* -- リストから目的の接続を選択し、*削除*をクリックします。操作を確認するには、 `delete`を指定されたフィールドに入力し、*削除*をクリックします。接続はリモートストレージオブジェクトのリストから削除されます。


. *保存*をクリックします。
+
変更した接続設定がリモート ストレージ オブジェクトに適用されます。
