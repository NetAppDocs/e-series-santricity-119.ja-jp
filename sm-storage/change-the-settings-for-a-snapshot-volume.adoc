= SANtricity System Managerでスナップショットボリュームのボリューム設定を変更する
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SnapshotボリュームまたはSnapshot整合性グループのSnapshotボリュームの設定では、Snapshotボリュームの名前を変更したり、SSDキャッシングを有効化 / 無効化したり、ホスト、ホスト クラスタ、または論理ユニット番号（LUN）の割り当てを変更できます。

.手順
. メニュー：Storage[Snapshots]を選択します。
. *Snapshot Volumes*タブをクリックします。
. 変更するスナップショットボリュームを選択し、*設定の表示/編集*をクリックします。
+
Snapshot Volume Settings ダイアログボックスが表示されます。

. Snapshotボリュームの設定を適宜表示、編集します。
+
.フィールドの詳細
[%collapsible]
====
[cols="25h,~"]
|===
| 設定 | 概要 


 a| 
* Snapshot ボリューム*



 a| 
Name
 a| 
Snapshotボリュームの名前を変更できます。



 a| 
割り当て先
 a| 
Snapshotボリュームのホストまたはホスト クラスタの割り当てを変更できます。



 a| 
LUN
 a| 
SnapshotボリュームのLUNの割り当てを変更できます。



 a| 
SSD キャッシュ
 a| 
ソリッド ステート ディスク（SSD）の読み取り専用キャッシュを有効 / 無効にできます。



 a| 
*関連オブジェクト*



 a| 
Snapshot イメージ
 a| 
スナップショットボリュームに関連付けられたスナップショットイメージを表示できます。スナップショットイメージは、特定のポイントインタイムで取得されたボリュームデータの論理的なコピーです。復元ポイントと同様に、スナップショットイメージを使用すると、既知の正常なデータセットにロールバックできます。ホストはスナップショットイメージにアクセスできますが、直接読み書きすることはできません。



 a| 
ベース ボリューム
 a| 
スナップショットボリュームに関連付けられているベースボリュームを表示できます。ベースボリュームとは、スナップショットイメージが作成される元のボリュームのことです。シックボリュームまたはシンボリュームのいずれかであり、通常はホストに割り当てられます。ベースボリュームは、ボリュームグループまたはディスクプールのどちらにも配置できます。



 a| 
Snapshot グループ
 a| 
スナップショットボリュームに関連付けられているスナップショットグループを表示できます。スナップショットグループとは、単一のベースボリュームから抽出されたスナップショットイメージの集合です。
