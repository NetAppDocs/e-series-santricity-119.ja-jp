= SANtricity System Managerで表形式のパフォーマンスデータを表示および保存
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
パフォーマンス グラフのデータを表形式で表示および保存することができます。これにより、表示するデータをフィルタできます。

.手順
. 任意のパフォーマンスデータグラフから、*Launch table view*をクリックします。
+
選択したオブジェクトのすべてのパフォーマンス データを示すテーブルが表示されます。

. 必要に応じて、オブジェクト選択のプルダウンとフィルタを使用します。
. *列の表示/非表示*ボタンをクリックして、表に含める列を選択します。
+
各チェック ボックスを使用して、項目を選択または選択解除できます。

. 画面下部の*エクスポート*を選択すると、表形式のビューがカンマ区切り値（CSV）ファイルとして保存されます。
+
「テーブルのエクスポート」ダイアログボックスが表示され、エクスポートする行数とエクスポートするファイル形式（カンマ区切り値、またはCSV形式）が表示されます。

. ダウンロードに進むには *Export* をクリックし、キャンセルするには *Cancel* をクリックしてください。
+
ブラウザの設定に応じて、ファイルが保存されるか、またはファイルの名前と場所を選択するよう求められます。

+
デフォルトのファイル名形式は `performanceStatistics-yyyy-mm-dd_hh-mm-ss.csv`で、ファイルがエクスポートされた日時が含まれます。
