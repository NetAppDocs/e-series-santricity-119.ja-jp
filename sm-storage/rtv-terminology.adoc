= SANtricity ソフトウェアのリモートストレージの用語について学ぶ
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ストレージ アレイに関連するリモート ストレージの用語を次に示します。

[cols="25h,~"]
|===
| 期間 | 概要 


 a| 
IQN
 a| 
iSCSI Qualified Name（IQN）の頭字語。iSCSIイニシエータまたはiSCSIターゲットの一意の名前です。



 a| 
LUN
 a| 
論理ユニット番号。論理ユニットを識別するために使用し、アクセス用にホストに提示可能です。



 a| 
リモート ストレージ システム
 a| 
最初にデータが存在するストレージ システム。リモート ストレージ システムは、Eシリーズ システムでも、別のベンダーのシステムでもかまいません。



 a| 
リモート ストレージ デバイス
 a| 
リモート システム上の、最初にデータが保存されている物理デバイスまたは論理デバイス。Eシリーズ ストレージ システムでは「ボリューム」と呼びます。



 a| 
リモート ストレージ オブジェクト
 a| 
Eシリーズ システムがリモート ストレージ システムを識別して接続するための情報を含むオブジェクト。リモート ストレージ システムのIQNとIPアドレスです。リモート ストレージ オブジェクトは、リモート ストレージ システムとEシリーズ システムの間の通信を表します。



 a| 
リモート ストレージ ボリューム
 a| 
リモート ストレージ デバイスへのデータ アクセスを許可するEシリーズ システム上の標準ボリューム。



 a| 
Volume
 a| 
データが格納されているコンテナ。ホストがデータにアクセスするために作成される論理コンポーネントです。

|===
