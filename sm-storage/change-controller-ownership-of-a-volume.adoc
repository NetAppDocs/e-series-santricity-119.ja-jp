= SANtricity System Managerでボリュームのコントローラ所有権を変更する
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ボリュームの優先コントローラ所有権を変更し、ホスト アプリケーションのI/Oが新しいパス経由で転送されるようにすることができます。

.開始する前に
マルチパス ドライバを使用しない場合は、現在ボリュームを使用しているホスト アプリケーションをすべてシャットダウンする必要があります。これによって、I/Oパスが変わる際のアプリケーション エラーを回避できます。

.タスク概要
プールまたはボリューム グループに含まれる1つまたは複数のボリュームのコントローラ所有権を変更することができます。

.手順
. メニュー：Storage[Volumes]を選択します。
. いずれかのボリュームを選択し、menu:More[Change ownership]を選択します。
+
「ボリューム所有権の変更」ダイアログボックスが表示されます。このダイアログボックスには、ストレージアレイ上のすべてのボリュームが表示されます。

. *優先所有者*ドロップダウンリストを使用して、変更する各ボリュームの優先コントローラを変更し、操作の実行を確認します。


.結果
* System Managerは、ボリュームのコントローラ所有権を変更します。ボリュームへのI/Oは、このI/Oパスを経由して行われるようになりました。
* マルチパス ドライバが新しいパスを認識するように再設定されるまで、ボリュームで新しいI/Oパスが使用されない場合があります。この処理は通常、5分未満で完了します。
