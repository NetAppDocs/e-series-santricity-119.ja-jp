= SANtricityソフトウェアのホスト用語について学ぶ
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ストレージ アレイに関連するホストの用語を次に示します。

[cols="25h,~"]
|===
| コンポーネント | 定義 


 a| 
ホスト
 a| 
ホストとは、ストレージアレイ上のボリュームにI/Oを送信するサーバーのことです。



 a| 
ホスト名
 a| 
ホスト名は、ホストのシステム名と同じである必要があります。



 a| 
ホスト クラスタ
 a| 
ホスト クラスタとは、ホストのグループのことです。ホスト クラスタを作成することで、同じボリュームを複数のホストに簡単に割り当てることができます。



 a| 
ホスト インターフェイス プロトコル
 a| 
ホスト インターフェイス プロトコルとは、コントローラとホスト間の接続（Fibre Channel、iSCSIなど）のことです。



 a| 
HBAまたはネットワーク インターフェイス カード（NIC）
 a| 
ホスト バス アダプタ（HBA）はホストに設置されるボードで、1つ以上のホスト ポートが搭載されています。



 a| 
ホスト ポート
 a| 
ホスト ポートは、コントローラに物理的に接続されるホスト バス アダプタ（HBA）のポートで、I/O処理に使用されます。



 a| 
ホスト ポートの識別子
 a| 
ホスト ポート識別子とは、ホスト バス アダプタ（HBA）上の各ホスト ポートに関連付けられた、世界共通の一意の名前です。

* Internet Small Computer System Interface（iSCSI）ホスト ポート識別子は、1～233文字である必要があります。iSCSIホスト ポート識別子は、標準のIQN形式で表示されます（例： `iqn.xxx.com.xxx:8b3ad`）。
* iSCSI 以外のホスト ポート識別子（Fibre Channel や Serial Attached SCSI（SAS）など）は、2 文字ごとにコロンで区切られて表示されます（例： `xx:yy:zz`）。Fibre Channel ホスト ポート識別子は 16 文字である必要があります。




 a| 
ホスト オペレーティング システム タイプ
 a| 
ホスト オペレーティング システム タイプは、ストレージ アレイ内のコントローラがホストのオペレーティング システム（またはそのバリアント）に応じてI/Oにどのように反応するかを定義する構成設定です。これは略して_ホスト タイプ_と呼ばれることもあります。



 a| 
コントローラのホスト ポート
 a| 
コントローラ ホスト ポートとは、ホストへの物理的な接続を提供するコントローラ上のポートで、I/O処理に使用されます。



 a| 
LUN
 a| 
論理ユニット番号（LUN）とは、ホストがボリュームにアクセスするために使用するアドレス空間に割り当てられた番号のことです。ボリュームは、LUNの形式で容量としてホストに提示されます。

各ホストには独自のLUNアドレス スペースがあります。そのため、同じLUNを複数のホストで使用して、異なるボリュームにアクセスできます。

|===
