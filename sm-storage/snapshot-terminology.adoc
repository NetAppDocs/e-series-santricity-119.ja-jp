= SANtricityソフトウェアのSnapshotの用語について学ぶ
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ストレージ アレイに関連するSnapshotの用語を次に示します。

[cols="25h,~"]
|===
| 期間 | 概要 


 a| 
Snapshot機能
 a| 
Snapshot機能は、ボリュームのイメージを作成および管理するために使用されます。



 a| 
Snapshot イメージ
 a| 
スナップショットイメージは、特定のポイントインタイムで取得されたボリュームデータの論理的なコピーです。復元ポイントと同様に、スナップショットイメージを使用すると、既知の正常なデータセットにロールバックできます。ホストはスナップショットイメージにアクセスできますが、直接読み書きすることはできません。



 a| 
ベース ボリューム
 a| 
ベースボリュームは、Snapshotイメージの作成元です。シックボリュームまたはシンボリュームのいずれかで、通常はホストに割り当てられます。ベースボリュームは、ボリュームグループまたはディスクプールのいずれかに配置できます。



 a| 
Snapshot ボリューム
 a| 
スナップショットボリュームを使用すると、ホストはスナップショットイメージ内のデータにアクセスできます。スナップショットボリュームには独自の予約容量があり、ベースボリュームへの変更を元のスナップショットイメージに影響を与えることなく保存します。



 a| 
Snapshot グループ
 a| 
スナップショットグループとは、単一のベースボリュームから抽出されたスナップショットイメージの集合です。



 a| 
リザーブ容量ボリューム
 a| 
予約容量ボリュームは、ベースボリュームのどのデータブロックが上書きされたか、およびそれらのブロックの保持されたコンテンツを追跡します。



 a| 
Snapshotスケジュール
 a| 
Snapshotスケジュールは、自動化されたSnapshotイメージを作成するためのスケジュール表です。スケジュールを通じて、イメージ作成の頻度を制御できます。



 a| 
Snapshot整合性グループ
 a| 
スナップショット整合性グループとは、スナップショットイメージを作成する際に単一のエンティティとして扱われるボリュームの集合です。これらの各ボリュームにはそれぞれ独自のスナップショットイメージがありますが、すべてのイメージは同じ時点で作成されます。



 a| 
Snapshot整合性グループ メンバー ボリューム
 a| 
スナップショット整合性グループに属する各ボリュームは、メンバーボリュームと呼ばれます。スナップショット整合性グループにボリュームを追加すると、System Managerは自動的に、そのメンバーボリュームに対応する新しいスナップショットグループを作成します。



 a| 
ロールバック
 a| 
ロールバックとは、ベースボリューム内のデータを以前のポイントインタイムに戻すプロセスです。



 a| 
リザーブ容量
 a| 
予約容量とは、あらゆるコピーサービス操作およびストレージオブジェクトに使用される、物理的に割り当てられた容量のことです。ホストから直接読み取ることはできません。

|===
