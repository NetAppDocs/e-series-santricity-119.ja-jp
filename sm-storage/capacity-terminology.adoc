= SANtricity ソフトウェアの容量に関する用語について学ぶ
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ストレージ アレイに関連する容量の用語を次に示します。



[[storage-objects]]
== ストレージ オブジェクト

次の用語は、ストレージ アレイを利用できるさまざまなタイプのストレージ オブジェクトを示しています。

[cols="25h,~"]
|===
| ストレージ オブジェクト | 概要 


 a| 
ホスト
 a| 
ホストとは、ストレージアレイ上のボリュームにI/Oを送信するサーバーのことです。



 a| 
LUN
 a| 
論理ユニット番号（LUN）とは、ホストがボリュームにアクセスするために使用するアドレス空間に割り当てられた番号のことです。ボリュームは、LUNの形式で容量としてホストに提示されます。

各ホストには独自のLUNアドレス スペースがあります。そのため、同じLUNを複数のホストで使用して、異なるボリュームにアクセスできます。



 a| 
ミラー整合性グループ
 a| 
ミラー整合性グループは、1つ以上のミラーペアを格納するコンテナです。非同期ミラーリング操作を行うには、ミラー整合性グループを作成する必要があります。



 a| 
ミラー ボリューム ペア
 a| 
ミラーペアは、プライマリボリュームとセカンダリ ボリュームの2つのボリュームで構成されます。



 a| 
プール
 a| 
プールは、論理的にグループ化されたドライブの集まりです。プールを使用して、ホストからアクセスできるボリュームを作成できます（ボリュームはプールまたはボリューム グループから作成します）。



 a| 
Snapshot整合性グループ
 a| 
スナップショット整合性グループとは、スナップショットイメージを作成する際に単一のエンティティとして扱われるボリュームの集合です。これらの各ボリュームにはそれぞれ独自のスナップショットイメージがありますが、すべてのイメージは同じ時点で作成されます。



 a| 
Snapshot グループ
 a| 
スナップショットグループとは、単一のベースボリュームから抽出されたスナップショットイメージの集合です。



 a| 
Snapshot ボリューム
 a| 
スナップショットボリュームを使用すると、ホストはスナップショットイメージ内のデータにアクセスできます。スナップショットボリュームには独自の予約容量があり、ベースボリュームへの変更を元のスナップショットイメージに影響を与えることなく保存します。



 a| 
Volume
 a| 
ボリュームとは、アプリケーション、データベース、ファイルシステムなどがデータを保存するコンテナのことです。これは、ホストがストレージアレイ上のストレージにアクセスするために作成される論理コンポーネントです。



 a| 
ボリューム グループ
 a| 
ボリュームグループとは、共通の特性を持つボリュームを格納するコンテナのことです。ボリュームグループには、定義された容量とRAIDレベルがあります。ボリュームグループを使用すると、ホストからアクセス可能な1つまたは複数のボリュームを作成できます。（ボリュームは、ボリュームグループまたはプールから作成します。）

|===


[[storage-capacity]]
== ストレージ容量

次の用語は、ストレージ アレイで使用されるさまざまなタイプの容量を示しています。

[cols="25h,~"]
|===
| 容量タイプ | 概要 


 a| 
割り当て容量
 a| 
割り当て容量は、プールまたはボリューム グループ内のドライブから割り当てられた物理容量です。

割り当てられた容量は、ボリュームの作成やコピー サービス操作に使用されます。



 a| 
空き容量
 a| 
空き容量とは、プールまたはボリュームグループ内で、ボリューム作成やコピーサービス操作、ストレージオブジェクトにまだ割り当てられていない容量のことです。



 a| 
プールまたはボリューム グループ容量
 a| 
プール、ボリューム、またはボリューム グループの容量は、ストレージ アレイ内の容量のうち、プールまたはボリューム グループに割り当てられている容量です。この容量は、ボリュームの作成のほか、コピー サービス処理やストレージ オブジェクトのさまざまな容量ニーズに対処するために使用されます。



 a| 
プールの使用不可容量
 a| 
プールの使用不可容量とは、ドライブのサイズが一致しないために使用できないプール内のスペースのことです。



 a| 
予約済み容量
 a| 
予約済み容量は、ドライブ障害に備えてプール内に確保されている容量（ドライブ数）です。



 a| 
レポート容量
 a| 
報告容量とは、ホストに報告され、ホストがアクセスできる容量のことです。



 a| 
リザーブ容量
 a| 
予約容量とは、あらゆるコピーサービス操作およびストレージオブジェクトに使用される、物理的に割り当てられた容量のことです。ホストから直接読み取ることはできません。



 a| 
SSD キャッシュ
 a| 
SSD Cacheは、ストレージアレイ内で論理的にグループ化されるSolid-State Disk（SSD）ドライブのセットのことです。SSD Cache機能は、最も頻繁にアクセスされるデータ（「ホット」データ）を低遅延のSSDドライブにキャッシュすることで、アプリケーションのワークロードを動的に高速化します。



 a| 
未割り当て容量
 a| 
未割り当て容量とは、ストレージアレイ内でプールまたはボリュームグループに割り当てられて*いない*領域のことです。



 a| 
書き込み済み容量
 a| 
書き込み容量とは、シンボリューム用に割り当てられた予約容量のうち、実際に書き込まれた容量のことです。

|===
