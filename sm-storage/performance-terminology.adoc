= SANtricity ソフトウェアのパフォーマンス用語について学ぶ
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ストレージ アレイに関連するパフォーマンスの用語を次に示します。

[cols="25h,~"]
|===
| 期間 | 概要 


 a| 
Application
 a| 
アプリケーションとは、SQLやExchangeなどのソフトウェア プログラムです。



 a| 
CPU
 a| 
CPUは、Central Pocessing Unit（中央処理装置）の略です。ストレージ アレイの処理能力のうち使用中の割合を示します。



 a| 
ホスト
 a| 
ホストとは、ストレージアレイ上のボリュームにI/Oを送信するサーバーのことです。



 a| 
IOPS
 a| 
IOPSは、1秒あたりの入出力操作数を表します。



 a| 
レイテンシ
 a| 
レイテンシとは、読み取りコマンドや書き込みコマンドなどの要求から、ホストまたはストレージ アレイからの応答までの時間間隔のことです。



 a| 
LUN
 a| 
論理ユニット番号（LUN）とは、ホストがボリュームにアクセスするために使用するアドレス空間に割り当てられた番号のことです。ボリュームは、LUNの形式で容量としてホストに提示されます。

各ホストには独自のLUNアドレス スペースがあります。そのため、同じLUNを複数のホストで使用して、異なるボリュームにアクセスできます。



 a| 
MiB
 a| 
MiBはmebibyte（mega binary byte）の略語です。1 MiBは220、つまり1,048,576バイトです。MB（10進数を表す）と比較してください。1 MBは1,024バイトに相当します。



 a| 
オブジェクト
 a| 
オブジェクトとは、論理的または物理的なストレージコンポーネントのことです。

論理オブジェクトには、ボリューム グループ、プール、ボリュームがあります。物理オブジェクトには、ストレージ アレイ、アレイ コントローラ、ホスト、ドライブがあります。



 a| 
プール
 a| 
プールは、論理的にグループ化されたドライブの集まりです。プールを使用して、ホストからアクセスできるボリュームを作成できます（ボリュームはプールまたはボリューム グループから作成します）。



 a| 
読み取り
 a| 
Readは「read operation（読み取り操作）」の略で、ホストがストレージアレイからデータを要求したときに発生します。



 a| 
Volume
 a| 
ボリュームとは、アプリケーション、データベース、ファイルシステムなどがデータを保存するコンテナのことです。これは、ホストがストレージアレイ上のストレージにアクセスするために作成される論理コンポーネントです。

ボリュームは、プールまたはボリュームグループで使用可能な容量から作成されます。ボリュームには、定義された容量があります。ボリュームは複数のドライブで構成される場合がありますが、ホストに対しては1つの論理コンポーネントとして表示されます。



 a| 
ボリューム名
 a| 
ボリューム名とは、ボリュームが作成された際に割り当てられる文字列のことです。デフォルトの名前を受け入れるか、ボリュームに保存されているデータの種類を示す、より分かりやすい名前を指定できます。



 a| 
ボリューム グループ
 a| 
ボリュームグループとは、共通の特性を持つボリュームを格納するコンテナのことです。ボリュームグループには、定義された容量とRAIDレベルがあります。ボリュームグループを使用すると、ホストからアクセス可能な1つまたは複数のボリュームを作成できます。（ボリュームは、ボリュームグループまたはプールから作成します。）



 a| 
ワークロード
 a| 
ワークロードは、アプリケーションをサポートするストレージ オブジェクトです。ワークロード（インスタンス）はアプリケーションごとに1つ以上定義できます。一部のアプリケーションについては、特性が似たボリュームで構成されるようにワークロードが設定されます。これらのボリューム特性は、ワークロードがサポートするアプリケーションのタイプに基づいて最適化されます。たとえば、Microsoft SQL Serverアプリケーションをサポートするワークロードを作成し、そのワークロード用のボリュームを作成すると、Microsoft SQL Serverをサポートするようにボリューム特性が最適化されます。



 a| 
書き込み
 a| 
「書き込み」とは「書き込み操作」の略で、ホストからアレイにデータが送信され、保存される操作を指します。

|===
