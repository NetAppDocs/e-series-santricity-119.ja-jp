= SANtricity System Managerでボリュームの容量を増やす
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
プールまたはボリューム グループ内の利用可能な空き容量を使用して、ボリュームのレポート容量（ホストに報告される容量）を拡張できます。

.開始する前に
* ボリュームの関連付けられたプールまたはボリューム グループに十分な空き容量が必要です。
* ボリュームが最適状態で、変更中の状態ではないことが必要です。
* シン ボリュームのレポート容量が最大値の256TiBに達していない必要があります。
* ボリュームでホット スペア ドライブが使用されていない必要があります（ボリューム グループ内のボリュームにのみ該当）。



NOTE: ボリューム容量は一度に最大128TiBまで拡張できます。

.タスク概要
このプールまたはボリューム グループで他のボリューム用に今後必要になる容量を考慮してください。Snapshotイメージ、Snapshotボリューム、またはリモート ミラーを十分に作成できる空き容量があることを確認してください。

[NOTE]
====
ボリュームの容量の拡張は、特定のオペレーティング システム上でのみサポートされています。サポートされていないホスト オペレーティング システム上でボリューム容量を拡張すると、拡張した容量は使用できなくなり、元のボリューム容量をリストアすることもできません。

====
.手順
. メニュー：Storage[Volumes]を選択します。
. 容量を増やしたいボリュームを選択し、次に*容量を増やす*を選択します。
+
[容量の拡張の確認]ダイアログ ボックスが表示されます。

. 続行するには*Yes*を選択してください。
+
[レポート容量の拡張]ダイアログ ボックスが表示されます。

+
このダイアログ ボックスには、ボリュームの現在のレポート容量と、ボリュームの関連付けられたプールまたはボリューム グループ内で使用可能な空き容量が表示されます。

. *Increase reported capacity by adding...*ボックスを使用して、現在報告されている利用可能な容量に容量を追加します。容量値の表示単位を、メビバイト（MiB）、ギビバイト（GiB）、またはテビバイト（TiB）のいずれかに変更できます。
. * Increase * をクリックします。


.結果
* System Managerは、選択に基づいてボリュームの容量を拡張します。
* メニューの「ホーム」→「進行中の操作を表示」を選択すると、選択したボリュームに対して現在実行中の容量増加操作の進行状況が表示されます。この処理には時間がかかり、システムのパフォーマンスに影響を与える可能性があります。


.終了後の操作
ボリュームの容量を拡張したら、それに応じてファイルシステムのサイズを手動で拡張する必要があります。方法は、使用しているファイルシステムによって異なります。詳細については、ホスト オペレーティング システムのドキュメントを参照してください。
