= SANtricity System Managerでスナップショット スケジュールをアクティブ化および一時停止する
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ストレージ スペースを節約する必要があるときは、スケジュールされているSnapshotイメージの収集を一時的に停止することができます。この方法は、Snapshotスケジュールを削除して作成し直すよりも効率的です。

.タスク概要
スナップショット スケジュールの状態は、* Activate *オプションを使用してスケジュールされたスナップショット アクティビティを再開するまで、一時停止状態のままになります。

.手順
. メニュー：Storage[Snapshots]を選択します。
. 表示されていない場合は、*スケジュール*タブをクリックしてください。
+
スケジュールの一覧が表示されます。

. 一時停止したいアクティブなスナップショットスケジュールを選択し、*アクティブ化／一時停止*をクリックします。
+
「状態」列のステータスが*一時停止*に変更され、スナップショットスケジュールはすべてのスナップショットイメージの収集を停止します。

. スナップショット イメージの収集を再開するには、再開する一時停止中のスナップショット スケジュールを選択し、*アクティブ化/一時停止*をクリックします。
+
「状態」列のステータスが *アクティブ* に変更されます。
