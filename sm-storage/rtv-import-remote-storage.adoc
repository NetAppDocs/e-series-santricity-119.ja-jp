= SANtricity System Manager でリモート ストレージをインポート
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
リモート システムからローカルのEシリーズ ストレージ システムへのストレージのインポートを開始するには、リモート ストレージ インポート ウィザードを使用します。

.開始する前に
* Eシリーズ ストレージ システムがリモート ストレージ システムと通信するように設定されている必要があります。
+
[NOTE]
====
ハードウェア構成については、 https://docs.netapp.com/us-en/e-series/remote-storage-volumes/setup-remote-volumes-concept.html["ハードウェアの設定"^]のEシリーズおよびSANtricityドキュメントセンターから入手できるリモート ストレージ機能のユーザーガイド、および https://www.netapp.com/pdf.html?item=/media/28697-tr-4893-deploy.pdf["リモート ストレージ テクニカル レポート"^]に記載されています。

====
* リモート ストレージ システムについて、次の情報を収集します。
+
** iSCSI IQN
** iSCSI IPアドレス
** リモート ストレージ デバイス（ソース ボリューム）のLUN番号


* ローカルのEシリーズ ストレージ システムで、データのインポートに使用するボリュームを作成または選択します。link:create-volumes.html["ボリュームの作成"]を参照してください。ターゲット ボリュームは次の要件を満たす必要があります。
+
** ブロック サイズがリモート ストレージ デバイス（ソース ボリューム）と同じである。
** リモート ストレージ デバイス以上の容量がある。
** 状態が「最適」で、かつ使用可能である。




要件の全リストについては、link:rtv-remote-storage-volume-requirements.html["リモート ストレージ ボリューム要件"]を参照してください。

* *推奨事項：* インポート処理を開始する前に、リモート システムのボリュームをバックアップしてください。


.タスク概要
このタスクでは、リモート ストレージ デバイスとローカルのEシリーズ ストレージ システム上のボリュームの間にマッピングを作成します。設定を終了すると、インポートが開始します。

[NOTE]
====
インポート操作とその完了時間には多くの要因が影響するため、まずは小規模な「`test`」インポートを実行することをお勧めします。これらのテストを使用して、すべての接続が期待どおりに機能し、インポート操作が適切な時間内に完了することを確認してください。

====
.手順
. メニュー：Storage[Remote storage]を選択します。
. *Import Remote Storage* をクリックします。
+
リモート ストレージをインポートするためのウィザードが表示されます。

. 「ソースの設定」パネルの「ステップ 1a」で、接続情報を入力します。別のiSCSI接続を追加する場合は、「別のIPアドレスを追加」をクリックして、リモート システム用のIPアドレスを追加してください。完了したら、「次へ」をクリックしてください。
+
.フィールドの詳細
[%collapsible]
====
[cols="25h,~"]
|===
| 設定 | 概要 


 a| 
Name
 a| 
System Managerでリモート ストレージ デバイスを識別するための名前を入力します。

名前は最大30文字までで、文字、数字、およびアンダースコア（_）、ダッシュ（-）、ハッシュ記号（#）などの特殊文字のみを含めることができます。名前にスペースを含めることはできません。



 a| 
iSCSI接続プロパティ
 a| 
リモート ストレージ デバイスの接続プロパティを入力します。

** *iSCSI Qualified Name（IQN）*：iSCSI IQN を入力してください。
** *IP Address*：IPv4アドレスを入力してください。
** *ポート*：送信元デバイスと送信先デバイス間の通信に使用するポート番号を入力してください。デフォルトでは、ポート番号は3260です。


|===
====
+
*Next*をクリックすると、Configure Sourceパネルの*Step 1b*が表示されます。

. *LUN*フィールドで、ソースとして使用するリモートストレージデバイスのLUN番号を選択し、*次へ*をクリックします。
+
[ターゲットの設定]パネルが開き、インポートのターゲットとなるボリュームの候補が表示されます。一部のボリュームは、ブロック サイズ、容量、またはボリュームの可用性が原因で候補リストに表示されません。

. 表から、Eシリーズ ストレージ システムのターゲットボリュームを選択します。必要に応じて、スライダーを使用してインポートの優先順位を変更します。*Next*をクリックします。次のダイアログボックスで、 `continue`と入力して操作を確認し、*Continue*をクリックします。
+
ターゲット ボリュームの容量がソース ボリュームよりも大きい場合、Eシリーズ システムに接続されているホストに追加分の容量は報告されません。新たな容量を使用するには、インポート処理が完了して切断されたあとに、ホストでファイルシステムの拡張処理を実行する必要があります。

+
ダイアログで設定を確定すると、[レビュー]パネルが表示されます。

. Reviewパネルで設定が正確であることを確認し、*Finish*をクリックしてインポートを開始します。
+
別のダイアログ ボックスが開き、別のインポートを開始するかどうかを確認するメッセージが表示されます。

. 必要に応じて、*Yes*をクリックして、別のリモートストレージインポートを作成してください。*Yes*をクリックすると、Configure Sourceパネルの*Step 1a*に戻り、既存の設定を選択するか、新しい設定を追加できます。別のインポートを作成しない場合は、*No*をクリックしてダイアログボックスを閉じます。
+
インポート プロセスが開始すると、ターゲット ボリューム全体がコピーされたデータで上書きされます。このプロセスの実行中にホストがターゲット ボリュームに新しいデータを書き込んだ場合、新しく書き込まれたデータはリモート デバイス（ソース ボリューム）に伝播されます。

. [リモート ストレージ]パネルの[処理を表示]ダイアログで、処理の進捗状況を確認します。


.結果
インポート処理が完了するまでの時間は、リモート ストレージ システムのサイズ、インポートの優先度設定、ストレージ システムと関連ボリュームの両方のI/O負荷によって異なります。

インポートが完了すると、ローカル ボリュームはリモート ストレージ デバイスの複製となります。

.終了後の操作
2つのボリューム間の関連付けを解除する準備ができたら、「進行中の操作」ビューからインポートオブジェクトの*切断*を選択します。接続が切断されると、ローカルボリュームのパフォーマンスは正常に戻り、リモート接続の影響を受けなくなります。
