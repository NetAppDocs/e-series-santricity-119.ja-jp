= SANtricity Unified Managerについて学ぶ
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity Unified ManagerはWebベースのインターフェイスで、複数のストレージアレイを単一のビューで管理できます。



[[main-page]]
== メイン ページ

Unified Managerにログインすると、メイン ページが*管理 - すべて*に開きます。このページから、ネットワーク内で検出されたストレージアレイの一覧をスクロールして確認したり、そのステータスを表示したり、単一のアレイまたはアレイのグループに対して操作を実行したりできます。



[[navigation-sidebar]]
== ナビゲーション サイドバー

ナビゲーション サイドバーからUnified Managerの各機能にアクセスできます。

[cols="25h,~"]
|===
| 領域 | 概要 


 a| 
管理
 a| 
ネットワーク内のストレージアレイを検出し、アレイのSANtricity System Managerを起動し、1つのアレイから複数のアレイに設定をインポートし、アレイグループを管理します。アレイ名の横にあるチェックボックスを選択すると、設定のインポートやアレイグループの作成など、アレイに対して操作を実行できます。各行の末尾にある省略記号は、名前変更など、単一のアレイに対する操作を行うためのインラインメニューを提供します。



 a| 
処理
 a| 
バッチ処理（アレイ間での設定のインポートなど）の進捗状況が表示されます。

[NOTE]
====
ストレージ アレイのステータスが最適でない場合は、一部の処理は使用できません。

====


 a| 
証明書管理
 a| 
ブラウザとクライアント間の認証を行う証明書を管理します。



 a| 
アクセス管理
 a| 
Unified Managerインターフェイスのユーザ認証を確立します。



 a| 
サポート
 a| 
テクニカル サポートのオプション、リソース、および連絡先が表示されます。

|===


[[interface-settings-and-help]]
== 画面の設定とヘルプ

画面右上からヘルプやその他のドキュメントにアクセスできます。ログイン名の横にあるドロップダウンから管理オプションにアクセスすることもできます。
