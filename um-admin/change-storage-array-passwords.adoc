= SANtricity Unified Managerでストレージアレイのパスワードを変更する
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity Unified Managerでストレージアレイの表示とアクセスに使用するパスワードを更新できます。

.開始する前に
* Storage Adminの権限を含むユーザ プロファイルでログインする必要があります。
* ストレージ アレイの現在のパスワード（System Managerで設定されているパスワード）を確認しておきます。


.タスク概要
このタスクでは、ストレージアレイの現在のパスワードを入力して、Unified Manager からアクセスできるようにします。System Manager でアレイのパスワードが変更され、さらに Unified Manager でも変更する必要がある場合は、この操作が必要になる可能性があります。

.手順
. 「管理」ページから、1つまたは複数のストレージアレイを選択します。
. メニュー：Uncommon Tasks[Provide Storage Array Passwords]を選択します。
. 各ストレージアレイのパスワードを入力し、*保存*をクリックします。
