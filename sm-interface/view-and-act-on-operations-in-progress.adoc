= SANtricity System Managerで進行中の処理を表示して操作します
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
長時間の処理を表示して、その処理に対する操作を実行するには、[実行中の処理]ページを使用します。

.タスク概要
[実行中の処理]ページに表示される処理ごとに、進捗状況と完了までの推定残り時間が表示されます。場合によっては、処理を停止したり、処理の優先度を変更したりできます。完了したボリューム コピー処理をリストから消去することもできます。

.手順
. ホーム画面で、*進行中の操作を表示*を選択します。
+
「進行中の作業」ページが表示されます。

. 必要に応じて、[操作]列のリンクを使用して、処理の停止または優先度の変更を行います。
+
[CAUTION]
====
特に、処理を停止する場合は、ダイアログ ボックスに表示されているすべての警告テキストをお読みください。

====
+
ボリューム コピー処理を停止するか、優先度を変更できます。

. ボリュームコピー操作が完了したら、*クリア*を選択してリストから削除できます。
+
ホームページの上部に、操作が完了すると情報メッセージと黄色のレンチアイコンが表示されます。このメッセージには、進行中の操作ページから操作をクリアできるリンクが含まれています。
