= SANtricity System Managerの操作進行中ページについて学ぶ
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
[実行中の処理]ページでは、長時間実行されていて、現在実行中、中断、停止、または障害状態の処理のリストを表示できます。処理のタイプによっては対処が可能です。

長時間実行されている処理はシステム パフォーマンスに影響することがあります。処理によっては、処理を停止したり、より重要な処理を先に完了させるために優先度を変更したりすることができます。
