[[how-do-performance-statistics-for-individual-volumes-relate-to-the-total]]
== 個々のボリュームのパフォーマンス統計と合計値との関係はどうなっていますか?

プールおよびボリューム グループの統計は、リザーブ容量用ボリュームを含むすべてのボリュームの集計によって計算されます。

リザーブ容量は、シン ボリューム、Snapshot、非同期ミラーリングをサポートするためにストレージ システムによって内部的に使用され、I/Oホストには表示されません。そのため、プール、コントローラ、およびストレージ アレイの統計は、表示可能なボリュームの合計ではない場合があります。

ただし、アプリケーションとワークロードの統計については、表示されるボリュームのみが集計されます。



[[why-does-data-display-as-zero-in-the-graphs-and-table]]
== グラフや表にデータが「0」（ゼロ）と表示されるのはなぜですか?

グラフや表のデータ ポイントにゼロと表示される場合は、その時点でオブジェクトのI/Oアクティビティがないことを意味します。ホストがそのオブジェクトへのI/Oを開始していないか、オブジェクト自体に問題がある可能性があります。

その場合もオブジェクトの履歴データは表示可能です。オブジェクトのI/Oアクティビティが発生し次第、ゼロ以外のデータが表示されます。

次の表に、各種オブジェクトについて、データ ポイント値がゼロになる最も一般的な理由を記載します。

[cols="25h,~"]
|===
| 配列レベルのオブジェクトタイプ | 理由データがゼロとして表示される 


 a| 
Volume
 a| 
* ボリュームにホストが割り当てられていない。




 a| 
ボリューム グループ
 a| 
* ボリューム グループがインポート中である。
* ボリューム グループにはホストに割り当てられているボリュームが含まれておらず、*_かつ_*ボリューム グループには予約済みの容量も含まれていません。




 a| 
ドライブ
 a| 
* ドライブで障害が発生している。
* ドライブが取り外されている。
* ドライブの状態が不明である。




 a| 
コントローラ
 a| 
* コントローラがオフラインになっている。
* コントローラで障害が発生している。
* コントローラが取り外されている。
* コントローラの状態が不明である。




 a| 
ストレージ アレイ
 a| 
* ストレージ アレイにボリュームが含まれていない。


|===


[[what-does-the-latency-graph-show]]
== [レイテンシ]グラフには何が表示されますか?

レイテンシーグラフは、ボリューム、ボリュームグループ、プール、アプリケーション、ワークロードごとのレイテンシー統計情報をミリ秒（ms）単位で表示します。このグラフは、[論理ビュー]、[物理ビュー]、[アプリケーションとワークロード ビュー]の各タブに表示されます。

レイテンシーとは、データの読み書き時に発生するあらゆる遅延を指します。グラフ上の任意の点にカーソルを合わせると、その時点における以下の値がミリ秒（ms）単位で表示されます：

* 読み取り時間
* 書き込み時間
* 平均I/Oサイズ




[[what-does-the-iops-graph-show]]
== [IOPS]グラフには何が表示されますか?

IOPSグラフは、1秒あたりの入出力操作数の統計情報を表示します。ホームページでは、このグラフにストレージアレイの統計情報が表示されます。パフォーマンスタイルの[論理ビュー]、[物理ビュー]、[アプリケーションとワークロードビュー]タブでは、このグラフにストレージアレイ、ボリューム、ボリュームグループ、プール、アプリケーション、ワークロードの統計情報が表示されます。

IOPSは「1秒あたりの入出力（I/O）操作数」の略です。グラフ上の任意の点にカーソルを合わせると、その時点における以下の値が表示されます：

* 読み取り処理の数
* 書き込み処理の数
* 読み取り処理と書き込み処理の合計数




[[what-does-the-mibs-graph-show]]
== [MiB/秒]グラフには何が表示されますか?

MiB/sグラフは、転送速度の統計情報を1秒あたりのメビバイト単位で表示します。ホームページでは、このグラフにストレージアレイの統計情報が表示されます。パフォーマンス タイルの[論理ビュー]、[物理ビュー]、[アプリケーションとワークロード ビュー]タブでは、このグラフにストレージ アレイ、ボリューム、ボリューム グループ、プール、アプリケーション、ワークロードの統計情報が表示されます。

MiB/sは_mebibytes per second_の略で、1秒あたり1,048,576バイトを意味します。グラフ上の任意の点にカーソルを合わせると、その時点における以下の値が表示されます：

* 読み取られたデータの量
* 書き込まれたデータの量
* 読み取られたデータと書き込まれたデータの合計量




[[what-does-the-cpu-graph-show]]
== [CPU]グラフには何が表示されますか?

CPUグラフは、各コントローラ（コントローラAとコントローラB）の処理能力統計を表示します。CPUは_central processing unit_の略です。ホームページでは、このグラフにストレージアレイの統計情報が表示されます。パフォーマンス タイルの [物理ビュー] タブでは、このグラフにストレージ アレイとドライブの統計情報が表示されます。

[CPU]グラフには、アレイでの処理に使用中のCPU処理能力の割合が示されます。外部I/Oが発生していないときでもCPU利用率がゼロにならないことがあります。これは、ストレージ オペレーティング システムがバックグラウンドで処理や監視を実行しているためです。グラフの特定のポイントにカーソルを合わせると、その時点における使用中の処理能力の割合が表示されます



[[what-does-the-headroom-graph-show]]
== [ヘッドルーム]グラフには何が表示されますか?

ヘッドルームグラフは、ストレージアレイコントローラの残存性能能力に関連しています。このグラフは、ホームページとパフォーマンスタイルの物理ビュータブに表示されます。

[ヘッドルーム]グラフには、ストレージ システムの物理オブジェクトの残りのパフォーマンス容量が示されます。グラフの特定のポイントにカーソルを合わせると、その時点におけるコントローラAとコントローラBの残りのIOPSおよびMiB/秒容量の割合が表示されます。
