= SANtricity System ManagerでシェルフIDを変更する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
シェルフIDは、ストレージ アレイ内のシェルフを一意に識別する番号です。シェルフに00または01から始まる連番が振られており、シェルフ画面の左上に表示されます。

.タスク概要
シェルフIDはコントローラ ファームウェアによって自動的に割り当てられますが、別の番号に変更することができます。

.手順
. *ハードウェア*を選択します。
. コントローラーシェルフまたはドライブシェルフのドロップダウンリストを選択し、次に*IDの変更*を選択します。
. 棚IDの変更ダイアログボックスで、ドロップダウンリストを選択して使用可能な番号を表示します。
+
このダイアログ ボックスにはアクティブなシェルフに現在割り当てられているIDは表示されません。

. 利用可能な番号を選択し、*保存*をクリックします。
+
選択した番号によっては、ハードウェアページの棚の並び順が変更される場合があります。必要に応じて、各棚の右上にある上下の矢印を使用して、順番を変更できます。
