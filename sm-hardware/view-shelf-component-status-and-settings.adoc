= SANtricity System Managerでシェルフコンポーネントのステータスと設定を表示
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
[ハードウェア]ページには、シェルフ コンポーネント（電源装置、ファン、バッテリなど）のステータスと設定が表示されます。

.タスク概要
使用可能なコンポーネントはシェルフのタイプによって異なります。

* *ドライブシェルフ* -- ドライブ、電源/ファンキャニスター、入出力モジュール（IOM）、およびその他のサポートコンポーネント一式を1つのシェルフに収納します。
* *Controller shelf* -- 1つの棚に、ドライブ一式、1つまたは2つのコントローラーキャニスター、電源/ファンキャニスター、およびその他のサポートコンポーネントを収納します。


.手順
. *ハードウェア*を選択します。
. コントローラシェルフまたはドライブシェルフのドロップダウンリストを選択し、次に*設定の表示*を選択します。
+
Shelf Components Settings ダイアログボックスが開き、シェルフコンポーネントに関連するステータスと設定を示すタブが表示されます。選択したシェルフのタイプによっては、表に記載されている一部のタブが表示されない場合があります。

+
[cols="25h,~"]
|===
| タブ | 概要 


 a| 
シェルフ
 a| 
*Shelf* タブには、以下のプロパティが表示されます：

** *Shelf ID* -- ストレージアレイ内のシェルフを一意に識別します。コントローラファームウェアがこの番号を割り当てますが、menu：Shelf[Change ID]を選択して変更できます。
** *シェルフパス冗長性* -- シェルフとコントローラ間の接続に代替方法が設定されているか（はい）、設定されていないか（いいえ）を指定します。
** *現在のドライブの種類* -- ドライブに組み込まれているテクノロジーの種類を示します（たとえば、セキュリティ機能を備えたSASドライブなど）。ドライブの種類が複数ある場合は、両方のテクノロジーが表示されます。
** *シリアル番号* -- シェルフのシリアル番号を表示します。




 a| 
IOM（ESM）
 a| 
*IOMs（ESMs）*タブには、入出力モジュール（IOM）のステータスが表示されます。IOMは環境サービスモジュール（ESM）とも呼ばれます。ドライブシェルフ内のコンポーネントのステータスを監視し、ドライブトレイとコントローラ間の接続ポイントとして機能します。

ステータスは、最適、失敗、最適（配線ミス）、または未認証のいずれかになります。その他の情報には、ファームウェアのバージョンと構成設定のバージョンが含まれます。

*その他の設定を表示*を選択すると、最大データレートと現在のデータレート、およびカード通信の状態（はいまたはいいえ）が表示されます。

[NOTE]
====
このステータスは、Shelfドロップダウンリストの横にあるIOMアイコンimage:../media/sam1130-ss-hardware-iom-icon.gif[""]を選択して確認することもできます。

====


 a| 
電源装置
 a| 
*Power Supplies*タブには、電源キャニスタと電源自体のステータスが表示されます。ステータスは、Optimal、Failed、Removed、またはUnknownのいずれかになります。電源の部品番号も表示されます。

[NOTE]
====
このステータスは、Shelfドロップダウンリストの横にある電源アイコンimage:../media/sam1130-ss-hardware-power-icon.gif[""]を選択して確認することもできます。

====


 a| 
ファン
 a| 
*ファン*タブには、ファンキャニスターとファン本体の状態が表示されます。ステータスは、最適、失敗、削除済み、または不明のいずれかになります。

[NOTE]
====
ファンアイコンimage:../media/sam1130-ss-hardware-fan-icon.gif[""]（シェルフドロップダウンリストの横）を選択することでも、このステータスを確認できます。

====


 a| 
温度
 a| 
*Temperature*タブには、センサー、コントローラー、電源/ファンキャニスターなど、シェルフコンポーネントの温度ステータスが表示されます。ステータスは、Optimal、Nominal temperature exceeded、Maximum temperature exceeded、またはUnknownのいずれかになります。

[NOTE]
====
温度アイコンimage:../media/sam1130-ss-hardware-temp-icon.gif[""]（シェルフドロップダウンリストの横）を選択することで、このステータスを確認することもできます。

====


 a| 
バッテリ
 a| 
*Batteries*タブには、コントローラーのバッテリーの状態が表示されます。ステータスは、Optimal、Failed、Removed、またはUnknownのいずれかになります。その他の情報には、バッテリーの寿命、交換までの日数、学習サイクル数、学習サイクル間の週数などが含まれます。

[NOTE]
====
シェルフのドロップダウンリストの横にあるバッテリーアイコンimage:../media/sam1130-ss-hardware-battery-icon.gif[""]を選択することでも、このステータスを確認できます。

====


 a| 
SFP
 a| 
*SFPs*タブには、コントローラ上のSmall Form-factor Pluggable（SFP）トランシーバのステータスが表示されます。ステータスは、Optimal、Failed、またはUnknownのいずれかになります。

*Show more settings* を選択すると、SFPの部品番号、シリアル番号、およびベンダーが表示されます。

[NOTE]
====
このステータスは、Shelfドロップダウンリストの横にあるSFPアイコンimage:../media/sam1130-ss-hardware-sfp-icon.gif[""]を選択して確認することもできます。

====
|===
. *閉じる* をクリックします。
