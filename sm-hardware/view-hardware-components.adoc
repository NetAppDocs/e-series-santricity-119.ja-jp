= SANtricity System Managerでハードウェアコンポーネントを表示
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
[ハードウェア]ページには、コンポーネントを検索しやすくするソートとフィルタの機能が表示されます。

.手順
. *ハードウェア*を選択します。
. 次の表に記載されている機能を使用してハードウェア コンポーネントを表示します。


[cols="25h,~"]
|===
| 機能 | 概要 


 a| 
ドライブ、コントローラ、およびコンポーネントのビュー
 a| 
前面と背面の棚表示を切り替えるには、右端から*Drives*または*Controllers & Components*を選択します（表示されるリンクは現在の表示によって異なります）。*Drives*ビューには、ドライブと空いているドライブベイが表示されます。*Controllers & Components*ビューには、コントローラー、IOM（ESM）モジュール、電源/ファンキャニスター、または空のコントローラーベイが表示されます。ページ下部にある*Show all drives*を選択することもできます。



 a| 
ドライブ表示のフィルタ
 a| 
ストレージアレイに、物理的属性と論理的属性が異なるタイプのドライブが含まれている場合、*Hardware*ページにはドライブビューフィルターが表示されます。これらのフィルターフィールドを使用すると、ページに表示されるドライブの種類を絞り込むことで、特定のドライブをすばやく見つけることができます。*Show drives that are...*の下にある左側のフィルターフィールドをクリックすると（デフォルトでは*Any drive type*が表示されます）、物理的な属性（容量や速度など）のドロップダウンリストが表示されます。右側のフィルターフィールドをクリックすると（デフォルトでは*Anywhere in the storage array*と表示されます）、論理属性のドロップダウンリスト（ボリュームグループの割り当てなど）が表示されます。これらのフィルターは、組み合わせて使用することも、個別に使用することもできます。

[NOTE]
====
ストレージアレイに含まれるドライブがすべて同じ物理属性を共有している場合、左側の*Any drive type*フィールドは表示されません。ドライブがすべて同じ論理的な場所にある場合、右側の*Anywhere in the storage array*フィールドは表示されません。

====


 a| 
凡例
 a| 
各コンポーネントは、それぞれの役割状態を示すために特定の色で表示されます。これらの状態の説明を展開したり折りたたんだりするには、*Legend*をクリックしてください。



 a| 
ステータス アイコンの詳細の表示
 a| 
ステータス表示には、可用性の状態に関するテキストによる説明を含めることができます。*Show status icon details*をクリックすると、このステータステキストの表示/非表示を切り替えることができます。



 a| 
シェルフ / シェルフ アイコン
 a| 
各シェルフビューには、関連するコマンドのリストと、そのプロパティおよびステータスが表示されます。*Shelf*をクリックすると、コマンドのドロップダウンリストが表示されます。上部にあるアイコンのいずれかを選択すると、コントローラー、IOM（ESM）、電源、ファン、温度、バッテリー、SFPなどの個々のコンポーネントの状態とプロパティを表示することもできます。



 a| 
シェルフの順序
 a| 
棚の配置は、ハードウェアのページで変更できます。各棚ビューの右上にある上下の矢印を使用して、棚の上下の順序を変更します。

|===
