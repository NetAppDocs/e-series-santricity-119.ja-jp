= SANtricity System Managerのドライブの状態について説明します
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity System Managerは、ドライブのさまざまな状態を報告します。



[[accessibility-states]]
== アクセスの状態

[cols="25h,~"]
|===
| 都道府県 | 定義 


 a| 
バイパス
 a| 
ドライブは物理的に存在しているが、コントローラはどちらのポートでもドライブと通信できない。



 a| 
互換性なし
 a| 
次のいずれかの状況に該当します。

* ストレージ アレイでの使用が認定されていないドライブです。
* ドライブのセクター サイズが異なります。
* ドライブの設定データが互換性のないファームウェア バージョンのものであり、使用できません。




 a| 
取り外し
 a| 
ドライブがストレージ アレイから取り外されています。



 a| 
現在
 a| 
コントローラは両方のポートでドライブと通信できます。



 a| 
応答なし
 a| 
ドライブがコマンドに応答していません。

|===


[[role-states]]
== ロールの状態

[cols="25h,~"]
|===
| 都道府県 | 定義 


 a| 
割り当て
 a| 
プールまたはボリューム グループのメンバーです。



 a| 
使用中のホット スペア
 a| 
障害が発生したドライブの交換用ドライブとして使用中です。ホット スペアはボリューム グループでのみ使用され、プールでは使用されません。



 a| 
スタンバイのホット スペア
 a| 
障害が発生したドライブの交換用ドライブとして使用可能な状態です。ホット スペアはボリューム グループでのみ使用され、プールでは使用されません。



 a| 
未割り当て
 a| 
このドライブは、プールまたはボリュームグループのメンバーではありません。

|===


[[availability-states]]
== 可用性の状態

[cols="25h,~"]
|===
| 都道府県 | 定義 


 a| 
失敗
 a| 
ドライブは動作していません。ドライブ上のデータは使用できません。



 a| 
障害の兆候
 a| 
ドライブで障害の前兆が検出されています。ドライブ上のデータはまだ使用できます。



 a| 
オフライン
 a| 
ドライブをデータの格納に使用できません。通常は、所属先のボリューム グループをエクスポート中であるか、ファームウェアのアップグレードを実行中であることが原因です。



 a| 
最適
 a| 
ドライブは正常に動作しています。

|===
