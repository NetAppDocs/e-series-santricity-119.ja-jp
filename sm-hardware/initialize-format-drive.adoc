= SANtricity System Manager でドライブを初期化（フォーマット）します
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ストレージ アレイから別のストレージ アレイへ、割り当てられたドライブを移動する場合、新しいストレージ アレイで使用するには、そのドライブを初期化（フォーマット）する必要があります。

.タスク概要
初期化すると、以前の設定情報がドライブから削除され、ドライブが未割り当て状態に戻ります。その後、ドライブは、新しいストレージ アレイの新しいプールまたはボリューム グループに追加可能になります。

単一のドライブを移動する場合は、ドライブの初期化処理を使用します。あるストレージ アレイから別のストレージ アレイへ、ボリューム グループ全体を移動する場合は、ドライブを初期化する必要はありません。

[CAUTION]
====
*データ損失の可能性* -- ドライブを初期化すると、ドライブ上のすべてのデータが失われます。この操作は、テクニカルサポートから指示があった場合にのみ実行してください。

====
.手順
. *ハードウェア*を選択します。
. グラフィックにコントローラが表示されている場合は、*ドライブ*タブをクリックします。
+
図の表示が切り替わり、コントローラではなくドライブが表示されます。

. 初期化するドライブをクリックします。
+
ドライブのコンテキスト メニューが表示されます。

. * Initialize * を選択し、操作を実行することを確認します。
