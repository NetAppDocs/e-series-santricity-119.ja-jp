= SANtricity System Managerでドライブロケーターライトを点灯する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
[ハードウェア]ページでは、ロケーター ライトを点灯して、ストレージ アレイ内のドライブの物理的な場所を特定できます。

.タスク概要
[ハードウェア]ページに表示される1本または複数のドライブを特定できます。

.手順
. *ハードウェア*を選択します。
. 1本以上のドライブを特定するには、次のいずれかを実行します。
+
** *シングルドライブ* -- シェルフの図から、アレイ内で物理的に配置するドライブを見つけます。（グラフィックにコントローラーが表示されている場合は、*ドライブ*タブをクリックしてください。）ドライブをクリックしてコンテキストメニューを表示し、*ロケーターライトを点灯*を選択します。
+
ドライブの位置情報ランプが点灯します。ドライブを物理的に特定したら、ダイアログに戻り、*Turn off*を選択してください。

** *複数のドライブ* -- フィルターフィールドで、左側のドロップダウンリストから物理ドライブの種類を選択し、右側のドロップダウンリストから論理ドライブの種類を選択します。条件に一致するドライブの数は、各フィールドの右端に表示されます。次に、*Turn on locator lights*をクリックするか、コンテキストメニューから*Locate all filtered drives*を選択します。ドライブを物理的に特定したら、ダイアログに戻り、*Turn off*を選択してください。
