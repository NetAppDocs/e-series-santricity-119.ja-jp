= SANtricity System Managerで棚の位置表示ライトを点灯する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
[ハードウェア]ページに表示されているシェルフの物理的な場所を特定するために、シェルフのロケーター ライトを点灯できます。

.手順
. *ハードウェア*を選択します。
. コントローラーシェルフまたはドライブシェルフのドロップダウンリストを選択し、次に*ロケーターライトを点灯*を選択します。
+
シェルフのロケーター ライトが点灯します。

. 棚の位置が確定したら、ダイアログボックスに戻り、*オフにする*を選択してください。
