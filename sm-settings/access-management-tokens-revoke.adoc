= SANtricity System Managerでアクセストークンを取り消す
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
トークンが漏えいしたと判断した場合、またはアクセス トークンの署名と検証に使用する暗号化キーを手動でローテーションしたい場合は、すべてのアクセス トークンを取り消すことができます。

この操作は、トークンの署名に使用される鍵を再生成します。鍵がリセットされると、発行済みのトークンは_すべて_即座に無効になります。ストレージアレイはトークンを追跡しないため、個々のトークンを取り消すことはできません。

.手順
. メニューの「設定」→「アクセス管理」を選択します。
. * Access Tokens * タブを選択します。
. * すべてのアクセストークンを取り消す * を選択します。
. ダイアログボックスで * はい * をクリックします。


すべてのトークンを取り消したら、新しいトークンを作成してすぐに使用できます。
