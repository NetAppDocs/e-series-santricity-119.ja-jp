= SANtricity System Managerでローカルユーザーのパスワード設定を変更します
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ストレージ アレイで新規作成または更新されるローカル ユーザ パスワードの最低文字数を設定できます。また、ローカル ユーザがパスワードを入力せずにストレージ アレイにアクセスできるようにすることもできます。

.開始する前に
ローカル管理者としてログインする必要があります。これにはRoot管理者権限が含まれます。

.タスク概要
ローカル ユーザ パスワードの最小文字数を設定する際には、次のガイドラインに注意してください。

* 設定を変更しても既存のローカル ユーザ パスワードには影響しません。
* ローカル ユーザ パスワードの最小文字数は、0～30文字にする必要があります。
* 新しいローカル ユーザ パスワードは、現在の最小文字数の設定以上にする必要があります。
* ローカル ユーザがパスワードを入力せずにストレージ アレイにアクセスできるようにする場合は、パスワードの最低文字数を設定しないでください。


.手順
. メニューの「設定」→「アクセス管理」を選択します。
. *ローカルユーザーロール*タブを選択します。
. *View/Edit Settings*ボタンを選択します。
+
ローカル ユーザー パスワード設定ダイアログ ボックスが開きます。

. 次のいずれかを実行します。
+
** ローカルユーザーがパスワードを入力せずにストレージアレイにアクセスできるようにするには、「すべてのローカルユーザーのパスワードを少なくとも必要とする」チェックボックスのチェックを外します。
** すべてのローカル ユーザ パスワードを対象にパスワードの最低文字数を設定するには、[Require all local user passwords to be at least]チェック ボックスをオンにし、スピン ボックスで最低文字数を設定します。
+
新しいローカル ユーザ パスワードは、現在の設定以上の長さにする必要があります。



. *保存*をクリックします。
