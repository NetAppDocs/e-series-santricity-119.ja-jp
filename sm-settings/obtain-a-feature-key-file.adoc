= SANtricity System Managerでフィーチャーキーファイルを取得する
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ストレージ アレイでプレミアム機能または機能パックを有効にするには、まず機能キー ファイルを取得する必要があります。キーは1つのストレージ アレイのみに関連付けられます。

.タスク概要
このタスクでは、必要な情報を収集し、機能キー ファイルのリクエストを送信する方法について説明します。必要な情報は次のとおりです。

* シャーシのシリアル番号
* 機能有効識別子
* Feature Activation Code


.手順
. System Managerで、シャーシのシリアル番号を確認し、記録してください。このシリアル番号は、[サポート センター]タイルの上にマウスを移動すると表示されます。
. System Managerで、Feature Enable Identifierを探します。メニューの「Settings」→「System」を選択し、下にスクロールして*Add-ons*を探してください。*Feature Enable Identifier*を探してください。Feature Enable Identifierの番号を記録してください。
. 機能をアクティブ化するためのコードを確認して記録します。機能パックの場合、このコードの確認方法は該当するドキュメントの変換手順に記載されています。
+
プレミアム機能の場合は、サポート サイトから次の手順でアクティベーション コードを入手できます。

+
..  https://mysupport.netapp.com/site/global/dashboard["NetAppサポート"^]にログインします。
.. お使いの製品の*ソフトウェアライセンス*に移動します。
.. ストレージアレイシャーシのシリアル番号を入力し、*Go*をクリックします。
.. *ライセンスキー*列で機能有効化コードを確認します。
.. 必要な機能のFeature Activation Codeを記録します。


. シャーシのシリアル番号、有効識別子、機能をアクティブ化するためのコードを記載したEメールまたは文書をストレージ サプライヤに送信して、機能キー ファイルをリクエストします。
+
また、 http://partnerspfk.netapp.com["NetAppライセンスアクティベーション：ストレージアレイプレミアム機能のアクティベーション"^]にアクセスして、機能または機能パックを入手するために必要な情報を入力してください。（このサイトの説明は、プレミアム機能に関するものであり、機能パックに関するものではありません。）



.終了後の操作
機能キー ファイルを取得したら、プレミアム機能または機能パックを有効にできます。
