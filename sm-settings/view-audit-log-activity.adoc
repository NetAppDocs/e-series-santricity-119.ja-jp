= SANtricity System Managerで監査ログのアクティビティを表示する
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Security Admin権限を持つユーザは、監査ログを表示して、ユーザによる操作、認証エラー、無効なログインの試行、およびユーザ セッションの期間を監視できます。

.開始する前に
Security Adminの権限を含むユーザ プロファイルでログインする必要があります。そうしないと、アクセス管理の機能は表示されません。

.手順
. メニューの「設定」→「アクセス管理」を選択します。
. **監査ログ**タブを選択します。
+
監査ログ アクティビティが表形式で表示されます。各列に表示される情報は次のとおりです。

+
** *日付/時刻* -- ストレージ アレイがイベントを検出した時刻のタイムスタンプ（GMT）。
** *ユーザー名* -- イベントに関連付けられたユーザー名。ストレージ アレイに対する認証されていない操作については、ユーザー名として「N/A」が表示されます。認証されていない操作は、内部プロキシまたはその他のメカニズムによってトリガーされる可能性があります。
** *ステータスコード* -- 操作の HTTP ステータスコード（200、400 など）と、イベントに関連付けられた説明テキスト。
** *アクセスしたURL* -- 完全なURL（ホストを含む）とクエリ文字列。
** *Client IP Address* -- イベントに関連付けられたクライアントのIPアドレス。
** *ソース* -- イベントに関連付けられたログソース。System Manager、CLI、Web Services、またはSupport Shellのいずれかになります。
** *概要* -- イベントに関する追加情報（該当する場合）。


. [監査ログ]ページで選択した内容を使用して、イベントを表示および管理します。
+
.選択項目の詳細
[%collapsible]
====
[cols="25h,~"]
|===
| 選択内容 | 概要 


 a| 
イベントを表示する期間を選択...
 a| 
表示されるイベントを日付範囲（過去24時間、過去7日間、過去30日間、カスタムの日付範囲）で限定します。



 a| 
フィルタ
 a| 
フィールドに入力された文字によって表示されるイベントを制限します。完全一致の場合は引用符（""）を使用し、 `OR`を入力して1つ以上の単語を返すか、ダッシュ（--）を入力して単語を省略します。



 a| 
更新
 a| 
最新のイベント情報にページを更新するには、*更新*を選択してください。



 a| 
設定の表示 / 編集
 a| 
*View/Edit Settings*を選択すると、ログポリシー全体とログに記録するアクションのレベルを指定できるダイアログボックスが開きます。



 a| 
イベントの削除
 a| 
*削除*を選択すると、ページから古いイベントを削除できるダイアログボックスが開きます。



 a| 
列の表示 / 非表示
 a| 
*表示/非表示*列アイコンimage:../media/sam-1140-ss-access-columns.gif["列の表示/非表示"]をクリックして、テーブルに表示する追加の列を選択します。追加の列には次のものがあります：

** *メソッド* -- HTTPメソッド（例：POST、GET、DELETEなど）。
** *CLI Command Executed* -- Secure CLIリクエストに対して実行されたCLIコマンド（文法）。
** *CLI 戻りステータス* -- CLI ステータス コードまたはクライアントからの入力ファイルの要求。
** *SYMbol手順* -- SYMbol手順が実行されました。
** *SSH イベントタイプ* -- ログイン、ログアウト、login_failなどのSecure Shell（SSH）イベントタイプ。
** *SSH Session PID* -- SSHセッションのプロセスID番号。
** *SSH Session Duration(s)* -- ユーザーがログインしていた秒数。
** *認証タイプ* -- タイプには、Local user、LDAP、SAML、およびAccess tokenが含まれます。
** *Authentication ID* -- 認証されたセッションのID。




 a| 
列フィルタを切り替え
 a| 
*Toggle* アイコン image:../media/sam-1140-ss-access-toggle.gif["切り替え"] をクリックして、各列のフィルタリングフィールドを開きます。列フィールドに文字を入力すると、その文字によって表示されるイベントが制限されます。フィルタリングフィールドを閉じるには、もう一度アイコンをクリックします。



 a| 
元に戻す変更
 a| 
*元に戻す*アイコンimage:../media/sam-1140-ss-access-undo.gif["元に戻す"]をクリックして、テーブルをデフォルト設定に戻します。



 a| 
エクスポート
 a| 
*Export*をクリックして、テーブルデータをカンマ区切り値（CSV）ファイルに保存します。
