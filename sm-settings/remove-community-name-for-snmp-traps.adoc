= SANtricity System ManagerでSNMPv2cトラップのコミュニティを削除する
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SNMPv2cトラップのコミュニティ名を削除できます。

.手順
. メニューの「設定」→「アラート」を選択します。
. * SNMP *タブを選択します。
+
トラップの送信先とコミュニティ名は、*アラート*ページに表示されます。

. * Configure Communities * を選択します。
+
「コミュニティの設定」ダイアログボックスが開きます。

. 削除するコミュニティ名を選択し、右端の*削除*（X）アイコンをクリックします。
+
トラップの宛先がこのコミュニティ名に関連付けられている場合、［コミュニティの削除の確認］ダイアログボックスに、影響を受けるトラップの宛先アドレスが表示されます。

. 操作を確認し、*削除*をクリックします。


.結果
コミュニティ名とそれに関連付けられたトラップの送信先は、アラートページから削除されます。
