= SANtricity System Managerでアラート用のsyslogサーバーを追加
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
syslogアラート用に最大5台のサーバを追加することができます。

.開始する前に
* syslogサーバのアドレスを確認しておく必要があります。このアドレスは、完全修飾ドメイン名、IPv4アドレス、またはIPv6アドレスのいずれかで指定できます。
* syslogサーバのUDPポート番号を確認しておく必要があります。通常は514です。


.手順
. メニューの「設定」→「アラート」を選択します。
. *Syslog*タブを選択します。
. *syslogサーバーの追加*を選択します。
+
[syslogサーバの追加]ダイアログ ボックスが開きます。

. *別のsyslogサーバを追加*を選択します。
. syslogサーバーの情報を入力し、*追加*をクリックします。
+
** * syslogサーバアドレス* -- 完全修飾ドメイン名、IPv4アドレス、またはIPv6アドレスを入力します。
** *UDPポート* -- 通常、syslogのUDPポートは514です。


+

NOTE: 最大5台のsyslogサーバを設定できます。



.結果
syslogサーバのアドレスが表に表示されます。
