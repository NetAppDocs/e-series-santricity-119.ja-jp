= SANtricity System Managerでのアドオン機能の仕組み
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
アドオンは、SANtricity System Managerの標準構成に含まれていない機能であり、有効化するためにキーが必要になる場合があります。アドオン機能は、単一のプレミアム機能またはバンドル機能パックのいずれかです。

以下は、プレミアム機能または機能パックを有効化するおおまかな手順です。

. 次の情報を入手します。
+
** シャーシのシリアル番号と機能有効識別子。機能をインストールするストレージ アレイを識別します。これらはSystem Managerで確認できます。
** Feature Activation Code。機能購入時にサポート サイトから入手できます。


. ストレージ プロバイダに問い合わせるか、Premium Feature Activationサイトにアクセスして、機能キーを取得します。シャーシのシリアル番号、有効識別子、およびFeature Activation Codeを指定します。
. System Managerで、機能キー ファイルを使用してプレミアム機能または機能パックを有効にします。
