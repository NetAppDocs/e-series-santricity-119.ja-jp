アクセス管理は、SANtricity System Managerでユーザ認証を確立する方法です。



[[what-authentication-methods-are-available]]
== 使用可能な認証方式にはどのようなものがありますか?

認証方式には、ロールベース アクセス制御（RBAC）、ディレクトリ サービス、およびSecurity Assertion Markup Language（SAML）があります。

* *RBAC/ローカルユーザロール* -- 認証は、ストレージアレイで適用されるRBAC機能によって管理されます。ローカルユーザロールには、事前定義されたユーザプロファイルと特定のアクセス権限を持つロールが含まれます。
* *ディレクトリサービス* -- 認証は、LDAP（Lightweight Directory Access Protocol）サーバと、MicrosoftのActive Directoryなどのディレクトリサービスを介して管理されます。
* *SAML* -- 認証は、SAML 2.0 を使用する ID プロバイダー（IdP）を介して管理されます。

== 認証を設定するにはどうすればよいですか?

ストレージアレイは、RBAC機能の実装であるローカルユーザロールを使用するように事前設定されています。別の方法を設定する場合は、メニューの［設定］［アクセス管理］に移動します。
