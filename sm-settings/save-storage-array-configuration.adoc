= SANtricity System Managerでストレージアレイ構成を保存
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ストレージアレイの設定情報をスクリプトファイルに保存することで、同じ設定を持つ追加のストレージアレイをセットアップする際の時間を節約できます。

.開始する前に
ストレージアレイは、論理構成設定を変更するような操作を受けていない状態である必要があります。これらの操作の例としては、ボリュームの作成または削除、コントローラファームウェアのダウンロード、ホットスペアドライブの割り当てまたは変更、ボリュームグループへの容量（ドライブ）の追加などが挙げられます。

.タスク概要
ストレージアレイの設定を保存すると、ストレージアレイの設定、ボリュームの設定、ホストの設定、またはストレージアレイのホストとボリュームの割り当てを含むコマンドラインインターフェイス（CLI）スクリプトが生成されます。この生成されたCLIスクリプトを使用すると、まったく同じハードウェア構成を持つ別のストレージアレイに構成を複製できます。

ただし、この生成されたCLIスクリプトを災害復旧に使用しないでください。代わりに、システム復元を行うには、手動で作成した構成データベースのバックアップファイルを使用するか、テクニカルサポートに連絡して最新のAuto-Supportデータからこのデータを入手してください。

この操作では、以下の設定は保存_されません_：

* バッテリの寿命
* コントローラの時刻
* 不揮発性静的ランダム アクセス メモリ（NVSRAM）の設定
* すべてのプレミアム機能
* ストレージ アレイのパスワード
* ハードウェア コンポーネントの動作ステータスおよび状態
* ボリューム グループの動作ステータス（最適を除く）および状態
* ミラーリング、ボリューム コピーなどのコピー サービス


[CAUTION]
====
*アプリケーションエラーのリスク* -- ストレージアレイが論理構成設定を変更する操作を実行している場合は、このオプションを使用しないでください。これらの操作の例としては、ボリュームの作成または削除、コントローラファームウェアのダウンロード、ホットスペアドライブの割り当てまたは変更、ボリュームグループへの容量（ドライブ）の追加などが挙げられます。

====
.手順
. メニュー：Settings[System]を選択します。
. *Save Storage Array Configuration* を選択します。
. 保存する構成の項目を選択します。
+
** ストレージ アレイの設定
** ボリューム構成
** ホスト構成
** ホスト / ボリューム間の割り当て


+
[NOTE]
====
*Host-to-volume assignments*項目を選択すると、*Volume configuration*項目と*Host configuration*項目もデフォルトで選択されます。「Volume configuration」と「Host configuration」を保存せずに「Host-to-volume assignments」を保存することはできません。

====
. *保存*をクリックします。
+
ファイルは、ブラウザのダウンロードフォルダに次の名前で保存されます `storage-array-configuration.cfg`。



.終了後の操作
保存したストレージアレイ構成を別のストレージアレイにロードするには、SANtricityコマンドラインインターフェイス（SMcli）と `-f`オプションを使用して `.cfg`ファイルを適用します。

[NOTE]
====
Unified Managerインターフェイスを使用して、ストレージアレイ構成を他のストレージアレイにロードすることもできます（メニュー：Manage[Import Settings]を選択）。

====
