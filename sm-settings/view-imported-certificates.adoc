= SANtricity System Managerでインポートされた証明書情報を表示する
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
[証明書]ページでは、証明書のタイプ、発行元認証局、およびストレージ アレイの証明書の有効な日付範囲を表示できます。

.開始する前に
Security Adminの権限を含むユーザ プロファイルでログインする必要があります。そうしないと、証明書関連の機能は表示されません。

.手順
. メニュー：Settings[Certificates]を選択します。
. いずれかのタブを選択して、証明書に関する情報を表示します。
+
[cols="25h,~"]
|===
| タブ | 概要 


 a| 
アレイ管理
 a| 
ルート ファイル、中間ファイル、サーバ ファイルなど、各コントローラ用にインポートしたCA署名証明書に関する情報が表示されます。



 a| 
信頼済み
 a| 
コントローラー用にインポートされたその他のすべての種類の証明書に関する情報を表示します。*Show certificates that are...*の下にあるフィルターフィールドを使用して、ユーザーがインストールした証明書またはプリインストールされた証明書のいずれかを表示します。

** *ユーザーインストール* -- ユーザーがストレージ アレイにアップロードした証明書。コントローラがクライアントとして動作する場合（サーバーではなく）の信頼された証明書、LDAPS証明書、およびIDフェデレーション証明書が含まれます。
** *プリインストール済み* -- ストレージアレイに付属している自己署名証明書。




 a| 
キー管理
 a| 
外部キー管理サーバ用にインポートしたCA署名証明書に関する情報が表示されます。

|===
