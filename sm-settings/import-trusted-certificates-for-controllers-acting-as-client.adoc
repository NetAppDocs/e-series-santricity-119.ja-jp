= SANtricity System Managerでコントローラがクライアントとして動作する場合の証明書のインポート
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ネットワーク サーバの信頼チェーンを検証できないためコントローラが接続を拒否する場合は、[信頼済み]タブから証明書をインポートして、コントローラ（クライアントとして機能）がそのサーバからの通信を受け入れるようにすることができます。

.開始する前に
* Security Adminの権限を含むユーザ プロファイルでログインする必要があります。そうしないと、証明書関連の機能は表示されません。
* 証明書ファイルはローカルシステムにインストールされています。


.タスク概要
別のサーバ（LDAPサーバや、TLSを使用するsyslogサーバなど）がコントローラにアクセスできるようにするには、[信頼済み]タブから証明書をインポートしなければならない場合があります。

.手順
. メニュー：Settings[Certificates]を選択します。
. 「信頼済み」タブから*インポート*を選択します。
+
信頼された証明書ファイルをインポートするためのダイアログ ボックスが表示されます。

. *参照*をクリックして、コントローラの証明書ファイルを選択します。
+
ダイアログ ボックスにファイル名が表示されます。

. *インポート*をクリックします。


.結果
ファイルがアップロードされて検証されます。
