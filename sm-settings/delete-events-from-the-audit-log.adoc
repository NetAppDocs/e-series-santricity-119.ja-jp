= SANtricity System Managerの監査ログからイベントを削除します
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
監査ログの古いイベントをクリアすることができます。これにより、イベントの検索が容易になります。削除時に古いイベントをCSV（カンマ区切り値）ファイルに保存することもできます。

.開始する前に
Security Adminの権限を含むユーザ プロファイルでログインする必要があります。そうしないと、アクセス管理の機能は表示されません。

.手順
. メニューの「設定」→「アクセス管理」を選択します。
. * Audit Log * タブを選択します。
. *Delete*を選択します。
+
監査ログの削除ダイアログボックスが開きます。

. 削除する古いイベントの数を選択または入力します。
. 削除したイベントをCSVファイルにエクスポートする場合（推奨）、チェックボックスをオンにしたままにしてください。次のステップで*削除*をクリックすると、ファイル名と保存場所を入力するよう求められます。それ以外の場合、イベントをCSVファイルに保存したくない場合は、チェックボックスをクリックして選択を解除してください。
. *削除*をクリックします。
+
確認のダイアログ ボックスが開きます。

. フィールドに `delete`と入力し、*削除*をクリックします。
+
[監査ログ]ページから古いイベントが削除されます。
