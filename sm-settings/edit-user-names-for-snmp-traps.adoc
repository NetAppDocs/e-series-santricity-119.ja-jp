= SANtricity System ManagerでSNMPv3トラップのユーザー設定を編集します
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SNMPv3トラップのユーザ定義を編集できます。

.開始する前に
SNMPv3トラップのユーザが作成されている必要があります。

.手順
. メニューの「設定」→「アラート」を選択します。
. * SNMP *タブを選択します。
+
トラップの送信先とユーザ名が表に表示されます。

. ユーザー定義を編集するには、表からユーザーを選択し、*ユーザー設定*をクリックします。
. ダイアログで、*View/Edit Settings* をクリックします。
. 次の情報を編集します。
+
** *ユーザー名* -- ユーザーを識別する名前を変更します。最大31文字まで入力できます。
** *Engine ID* -- メッセージの認証キーと暗号化キーを生成するために使用されるEngine IDを選択します。このIDは管理ドメイン内で一意である必要があります。ほとんどの場合、*Local*を選択してください。標準以外の構成の場合は、*Custom*を選択してください。別のフィールドが表示されるので、そこに権限のあるエンジンIDを10～32文字の偶数文字の16進数文字列として入力する必要があります。
** *認証クレデンシャル* -- 認証プロトコルを選択します。これにより、ユーザーの ID が保証されます。次に、認証パスワードを入力します。これは、認証プロトコルが設定または変更されたときに必要です。パスワードは 8 ～ 128 文字である必要があります。
** *プライバシークレデンシャル* -- メッセージの内容の暗号化に使用されるプライバシープロトコルを選択します。次に、プライバシーパスワードを入力します。これは、プライバシープロトコルが設定または変更されたときに必要です。パスワードは8～128文字である必要があります。




.結果
[アラート]ページの[SNMP]タブに、更新された設定が表示されます。
