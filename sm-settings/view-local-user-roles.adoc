= SANtricity System Managerでローカルユーザーロールを表示する
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
「ローカルユーザーロール」タブでは、ユーザープロファイルと既定のロールのマッピングを表示できます。これらのマッピングは、ストレージアレイで適用されるRBAC（ロールベースアクセス制御）の一部です。

.開始する前に
Security Adminの権限を含むユーザ プロファイルでログインする必要があります。そうしないと、アクセス管理の機能は表示されません。

.タスク概要
ユーザ プロファイルとマッピングを変更することはできません。変更できるのはパスワードのみです。

.手順
. メニューの「設定」→「アクセス管理」を選択します。
. *ローカルユーザーロール*タブを選択します。
+
ユーザ プロファイルがテーブルに表示されます。

+
** *ルート管理者*（admin）-- システム内のすべての機能にアクセスできるスーパー管理者。このユーザープロファイルには、すべてのロールが含まれています。
** *ストレージ管理者*（storage）-- すべてのストレージ プロビジョニングを管理する管理者。このユーザープロファイルには、Storage Admin、Support Admin、Monitorの役割が含まれています。
** *セキュリティ管理者*（セキュリティ）-- セキュリティ設定を担当するユーザー。アクセス管理、証明書管理、およびセキュリティ対応ドライブ機能が含まれます。このユーザープロファイルには、Security AdminとMonitorという役割が含まれています。
** *サポート管理者*（サポート）-- ハードウェア リソース、障害データ、ファームウェアのアップグレードを担当するユーザ。このユーザ プロファイルには、サポート管理者とモニタの役割が含まれます。
** *Monitor* (monitor) -- システムへの読み取り専用アクセス権を持つユーザー。このユーザープロファイルには、Monitorロールのみが含まれています。
