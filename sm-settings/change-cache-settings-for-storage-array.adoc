= SANtricity System Managerでストレージアレイのキャッシュ設定を変更する
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ストレージ アレイ内のすべてのボリュームでは、フラッシュおよびブロック サイズについてキャッシュ メモリの設定を調整できます。

.タスク概要
キャッシュ メモリは、ドライブ メディアよりも速くアクセスできる、コントローラ上の一時的な揮発性ストレージ領域です。キャッシュのパフォーマンスをチューニングする場合は、次の設定を調整できます。

[cols="25h,~"]
|===
| キャッシュ設定 | 概要 


 a| 
デマンド キャッシュ フラッシュの開始
 a| 
デマンドキャッシュフラッシュの開始は、キャッシュフラッシュ（ディスクへの書き込み）をトリガーするキャッシュ内の未書き込みデータの割合を指定します。デフォルトでは、未書き込みデータが容量の80%に達するとキャッシュフラッシュが開始されます。書き込み処理が主な環境では、より高い割合を設定することをお勧めします。これにより、新しい書き込み要求をディスクにアクセスすることなくキャッシュで処理できます。I/Oが不安定な環境（データバーストを伴う環境）では、低い設定の方が適しています。これにより、システムはデータバーストの合間にキャッシュを頻繁にフラッシュします。ただし、開始率が80%を下回ると、パフォーマンスが低下する可能性があります。



 a| 
キャッシュ ブロック サイズ
 a| 
キャッシュブロックサイズは、キャッシュ管理における組織単位である各キャッシュブロックの最大サイズを決定します。デフォルトでは、ブロックサイズは32 KiBです。このシステムでは、キャッシュブロックサイズを4、8、16、または32 KiBsに設定できます。アプリケーションによって使用するブロックサイズが異なるため、ストレージのパフォーマンスに影響が出ます。ファイルシステムやデータベースアプリケーションには、より小型のサイズが適しています。より大きなサイズは、マルチメディアなど、シーケンシャルI/Oを行うアプリケーションに最適です。

|===
.手順
. メニュー：Settings[System]を選択します。
. *Additional Settings*までスクロールダウンし、*Change Cache Settings*をクリックします。
+
[キャッシュ設定の変更]ダイアログ ボックスが開きます。

. 次の値を調整します。
+
** *デマンドキャッシュのフラッシュを開始します* -- ご使用の環境で使用されるI/Oサイズに適したパーセンテージを選択してください。80%未満の値を選択すると、パフォーマンスが低下する可能性があります。
** **キャッシュ ブロック サイズ -- **アプリケーションに適したサイズを選択してください。


. *保存*をクリックします。
