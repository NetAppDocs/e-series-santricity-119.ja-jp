== Version 11.90R4の新機能

このバージョンにはマイナーな変更のみが含まれており、新しい機能は含まれていません。このリリースの変更点の詳細については、Eシリーズ SANtricity OS 11.90R4 READMEを参照してください。



== Version 11.90R3の新機能

[cols="35h,~"]
|===
| 新機能 | 概要 


 a| 
IOM12CおよびDCM3のSANtricity OSサポート
 a| 
コントローラファームウェア11.90R3以降では、IOM12CおよびDCM3 SAS-3シェルフのサポートが利用可能になりました。IOM12CおよびDCM3シェルフは、IOM12BおよびDCM2シェルフの後継機種です。

|===

== Version 11.90R1の新機能

[cols="35h,~"]
|===
| 新機能 | 概要 


 a| 
新しいストレージ システム モデル – EF300CおよびEF600C
 a| 
今回のリリースでは、EF300CおよびEF600CというオールフラッシュNVMeストレージシステムを紹介します。EF300CとEF600Cは、既存のEF300およびEF600ストレージシステムの大容量フラッシュバージョンです。EF300CおよびEF600Cは、30TBまたは60TBサイズの大容量NVMe SSDドライブに対応しています。EF300C/EF600Cは、ダイナミックディスクプールでの使用のみに対応しており、従来のRAIDには対応していません。



 a| 
EF4000の12Gb SASインターフェースのサポート
 a| 
E4000コントローラは12Gb SASホスト インターフェイス カードをサポートするようになりました。

|===


== バージョン11.90の新機能

[cols="35h,~"]
|===
| 新機能 | 概要 


 a| 
新しいストレージ システム モデル – E4000
 a| 
このリリースでは、低コストストレージシステムE4000が導入されました。E4000は、12台および60台のドライブと、コントローラあたり1枚のホスト インターフェイス カード（HIC）をサポートしています。初回リリースでは、サポートされるホスト インターフェイス カードにはiSCSIとFibre Channelが含まれます。E4000ストレージシステムおよびその他のEシリーズ ストレージシステムは、Unified Managerで表示および管理できます。



 a| 
Dynamic Disk Poolの容量増加
 a| 
ダイナミック ディスク プール（DDP）の容量は、プール内の個々のドライブの容量が23TBを超える場合、12PBに増加されました。個々のドライブの容量が23TB未満の場合、DDPの容量は6PBとなります。



 a| 
デフォルトのメディアスキャン設定が増加しました
 a| 
デフォルトのメディアスキャン間隔が120日に延長されました。



 a| 
外部キー管理でプライベートキーが使用可能になりました
 a| 
秘密鍵と公開鍵のペアを使用して外部で生成された証明書署名要求（CSR）ファイルを、System Managerからインポートできるようになりました。



 a| 
Web Servicesでログインロックアウト機能が利用可能になりました
 a| 
REST APIを介してのみ設定可能で、組み込み型およびプロキシ型Webサービス向けに、新しいログインロックアウト設定が利用可能になりました。

|===
