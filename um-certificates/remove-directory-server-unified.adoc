= ディレクトリ サーバの削除
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ディレクトリ サーバとWebサービス プロキシの間の接続を切断するには、[アクセス管理]ページでサーバ情報を削除します。このタスクは、新しいサーバの設定が完了して古いサーバを削除する場合などに実行します。

.開始する前に
Security Adminの権限を含むユーザ プロファイルでログインする必要があります。そうしないと、アクセス管理の機能は表示されません。

.タスク概要
このタスクが完了すると、アクティブなユーザーセッションはすべて終了します。現在のユーザーセッションのみが保持されます。

.手順
. *アクセス管理*を選択します。
. *Directory Services*タブを選択します。
. 削除するディレクトリ サーバをリストから選択します。
. *削除*をクリックします。
+
「ディレクトリサーバーの削除」ダイアログボックスが開きます。

. フィールドに `remove`と入力し、*削除*をクリックします。
+
ディレクトリ サーバ設定、権限設定、ロール マッピングが削除されます。ユーザは、以降このサーバからのクレデンシャルを使用してログインすることはできません。
