= 証明書の表示
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
証明書を使用している組織、発行元の機関、有効期間、フィンガープリント（一意の識別子）など、証明書の概要情報を表示できます。

.開始する前に
Security Adminの権限を含むユーザ プロファイルでログインする必要があります。そうしないと、証明書関連の機能は表示されません。

.手順
. * Certificate Management * を選択します。
. 次のいずれかのタブを選択します。
+
** *管理* -- Webサービスプロキシをホストしているシステムの証明書を表示します。管理証明書は、自己署名式または認証局（CA）による承認式のいずれかを選択できます。これにより、Unified Managerへの安全なアクセスが可能になります。
** *信頼済み* -- Unified Manager がストレージ アレイやその他のリモート サーバー（LDAPサーバなど）にアクセスするために使用できる証明書を表示します。証明書は認証局（CA）から発行することも、自己署名することも可能です。


. 証明書に関する詳細情報を表示するには、該当する行を選択し、行末尾の省略記号を選択してから、*View*または*Export*をクリックします。
