= SANtricity Unified Managerのミラーリング用語について学ぶ
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ストレージ アレイに関連するミラーリングの用語を次に示します。

[cols="25h,~"]
|===
| 期間 | 概要 


 a| 
ローカル ストレージ アレイ
 a| 
ローカル ストレージ アレイは、操作の対象となるストレージ アレイです。



 a| 
ミラー整合性グループ
 a| 
ミラー整合性グループは、1つ以上のミラーペアを格納するコンテナです。非同期ミラーリング処理では、ミラー整合性グループを作成する必要があります。グループ内のすべてのミラーペアが同時に再同期されるため、一貫したリカバリポイントが維持されます。

同期ミラーリングではミラー整合性グループを使用しません。



 a| 
ミラー ペア
 a| 
ミラーペアは、プライマリボリュームとセカンダリ ボリュームの2つのボリュームで構成されます。

非同期ミラーリングでは、ミラーリングされたペアは常にミラー整合性グループに属します。書き込み操作はまずプライマリ ボリュームに対して実行され、次にセカンダリ ボリュームにレプリケートされます。ミラー整合性グループ内の各ミラーペアは、同じ同期設定を共有します。



 a| 
プライマリ ボリューム
 a| 
ミラーリングされたペアのプライマリボリュームは、ミラーリングされるソースボリュームです。



 a| 
リモート ストレージ アレイ
 a| 
リモートストレージアレイは通常、セカンダリサイトとして指定され、ミラーリング構成でデータのレプリカを保持するのが一般的です。



 a| 
リザーブ容量
 a| 
予約容量とは、あらゆるコピーサービス操作およびストレージオブジェクトに使用される、物理的に割り当てられた容量のことです。ホストから直接読み取ることはできません。

ミラーリングの動作状態を維持するために必要な情報をコントローラが永続的に保存できるようにするには、これらのボリュームが必要です。これらのボリュームには、差分ログやcopy-on-writeデータなどの情報が格納されます。



 a| 
セカンダリ ボリューム
 a| 
ミラーペアのセカンダリ ボリュームは通常、セカンダリサイトに配置され、データの複製を保持します。



 a| 
同期
 a| 
同期は、ローカルストレージアレイとリモートストレージアレイ間の初期同期時に発生します。通信の中断後にプライマリボリュームとセカンダリ ボリュームの同期が解除された場合にも、同期処理が行われます。通信リンクが再び機能すると、複製されていないデータはすべてセカンダリ ボリュームのストレージアレイに同期されます。

|===
