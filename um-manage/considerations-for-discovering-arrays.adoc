= SANtricity Unified Managerでのストレージアレイの検出について学ぶ
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity Unified Managerがストレージリソースを表示および管理する前に、組織のネットワーク内で管理するストレージアレイを検出する必要があります。複数のアレイを検出することも、単一のアレイを検出することもできます。



== 複数のストレージ アレイの検出

複数のアレイを検出することを選択した場合、ネットワークIPアドレスの範囲を入力すると、Unified Managerはその範囲内の各IPアドレスに対して個別に接続を試みます。アクセスに成功したストレージアレイは「検出」ページに表示され、管理ドメインに追加できます。



== 単一のストレージ アレイの検出

単一のアレイを検出する場合は、ストレージ アレイのいずれかのコントローラのIPアドレスを1つ入力すると、そのストレージ アレイが追加されます。

[NOTE]
====
Unified Managerは、コントローラに割り当てられた単一のIPアドレス、または範囲内のIPアドレスのみを検出して表示します。これらのコントローラに割り当てられた代替コントローラまたはIPアドレスが、この単一のIPアドレスまたはIPアドレス範囲外にある場合、Unified Managerはそれらを検出または表示しません。ただし、ストレージアレイを追加すると、関連付けられているすべてのIPアドレスが検出され、管理ビューに表示されます。

====


== ユーザ クレデンシャル

検出プロセスでは、追加する各ストレージ アレイの管理者パスワードが必要になります。



== Webサービスの証明書

検出プロセスの一環として、Unified Managerは検出されたストレージアレイが信頼できるソースの証明書を使用していることを確認します。Unified Managerは、ブラウザとのすべての接続において、2種類の証明書ベースの認証方式を使用します：

* *信頼できる証明書*
+
Unified Managerによって検出されたアレイの場合、認証局から提供される追加の信頼できる証明書をインストールする必要がある場合があります。

+
これらの証明書をインポートするには、*Import*ボタンを使用してください。以前にこのアレイに接続したことがある場合、コントローラー証明書の一方または両方が期限切れ、失効、あるいは証明書チェーンにルート証明書または中間証明書が欠落している可能性があります。ストレージアレイを管理する前に、期限切れまたは失効した証明書を交換するか、不足しているルート証明書または中間証明書を追加する必要があります。

* *自己署名証明書*
+
自己署名証明書も使用できます。管理者が署名付き証明書をインポートせずにアレイの検出を試みた場合、Unified Manager はエラーダイアログボックスを表示し、管理者が自己署名証明書を受け入れることができます。ストレージアレイの自己署名証明書は信頼済みとしてマークされ、ストレージアレイは Unified Manager に追加されます。

+
ストレージアレイへの接続を信頼しない場合は、*キャンセル* を選択し、ストレージアレイを Unified Manager に追加する前にストレージアレイのセキュリティ証明書戦略を検証してください。
