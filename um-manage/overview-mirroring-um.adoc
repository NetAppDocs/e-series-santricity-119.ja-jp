= SANtricity Unified Managerでのミラーリングについて学ぶ
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ミラーリング機能を使用して、ローカル ストレージ アレイとリモート ストレージ アレイの間でデータを非同期または同期的にレプリケートします。

[NOTE]
====
EF600/EF600CまたはEF300/EF300Cストレージ システムでは、同期ミラーリングは利用できません。

====


[[what-is-mirroring]]
== ミラーリングとは何ですか?

SANtricityアプリケーションには2種類のミラーリング（非同期と同期）があります。非同期ミラーリングでは、データ ボリュームをオンデマンドで、またはスケジュールに基づいてコピーします。これにより、データの破損や損失が原因で発生するダウンタイムを回避または最小限に抑えることができます。同期ミラーリングでは、データ ボリュームをリアルタイムでレプリケートして、継続的な可用性を確保します。

詳細については、以下を参照してください。

* link:mirroring-overview.html["ミラーリングの仕組み"]
* link:mirroring-terminology.html["ミラーリングに関する用語"]




[[how-do-i-configure-mirroring]]
== ミラーリングを設定するにはどうすればよいですか?

Unified Managerで非同期または同期ミラーリングを設定し、System Managerを使用して同期を管理します。

* link:create-synchronous-mirrored-pair-um.html["同期ミラー ペアの作成"]
